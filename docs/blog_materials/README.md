## ブログにするときのルール

- 個人名、元資料名、Google Docsリンク、元チャート画像は載せない
- 「誰が失敗したか」ではなく「どんな心理が起きやすいか」に変換する
- 数字は必要最小限にする
- 売買推奨ではなく、観察・学習・検証として書く
- 読者がすぐ使える言葉にする
  - STOP = 今すぐ入らない
  - WAIT = 待つ
  - CHECK = 損切り位置と上位足を確認する
