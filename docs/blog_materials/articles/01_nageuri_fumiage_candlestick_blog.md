# 投げ売りは、大陰線の終わりではなく反発前の損切り集中で起きる

作成日: 2026-06-01  
用途: ブログ記事下書き

## この記事で伝えること

トレードで大きく動く場面には、ただ価格が動いているだけではなく、そこにいる人たちの心理が出ています。

特にわかりやすいのが、**投げ売り** と **踏み上げ** です。

この2つは難しい言葉に見えますが、実はどちらも同じ構造です。

> 負けている側が、もう耐えられなくなって決済する。

その決済が連鎖すると、価格は一気に動きます。

## 投げ売りとは

投げ売りとは、買っていた人たちが耐えられなくなり、一斉に売ることです。

たとえば、上昇しているチャートを見て、多くの人が「まだ上がる」と考えて買います。ところが高値を更新できなくなり、上ヒゲが出て、次に大きな陰線が出る。さらに直近安値やサポートを割ってしまう。

この瞬間、買っていた人たちはこう考えます。

```text
これはまずい
もう上がらないかもしれない
損が広がる前に逃げたい
```

この逃げるための売りが重なると、下落が加速します。これが投げ売りです。

ローソク足で見ると、典型的にはこのような流れです。

```text
連続陽線
-> 上ヒゲ陰線
-> 包み陰線
-> サポート割れ大陰線
```

ポイントは、単に陰線が出たことではありません。

それまで買い手が強気だった場所で、上昇期待が否定されることが大切です。

## 踏み上げとは

踏み上げとは、売っていた人たちが耐えられなくなり、一斉に買い戻すことです。

たとえば、大きく下落したチャートを見ると、多くの人が「まだ下がる」と考えて売ります。ところが、そこから思ったほど下がらない。安値を更新できず、下ヒゲが何本も出る。安値圏で小さなレンジを作り、その後にレンジ高値を上に抜ける。

この瞬間、売っていた人たちはこう考えます。

```text
下がらない
売りが失敗したかもしれない
これ以上上がると損切りになる
```

ショートの損切りは、買い戻しです。そこに新規の買いも重なると、上昇が一気に強くなります。これが踏み上げです。

ローソク足で見ると、典型的にはこのような流れです。

```text
急落
-> 下ヒゲ連発
-> 安値圏の小レンジ
-> レンジ上抜け大陽線
```

ここで大切なのは、急落したからすぐ買うことではありません。

一度大きく下げたあとに、**それ以上下がらない時間** があるかを見ることです。

## 投げ売りと踏み上げの共通点

投げ売りと踏み上げは、向きは逆ですが、心理は同じです。

| 現象 | 降参する側 | 決済の方向 | 価格の動き |
|---|---|---|---|
| 投げ売り | 買い手 | 売る | 下落が加速 |
| 踏み上げ | 売り手 | 買い戻す | 上昇が加速 |

どちらも、負けている側の損切りが燃料になります。

つまり、チャートを見るときは「次に買う人がいるか」「次に売る人がいるか」だけでなく、こう考えると見え方が変わります。

```text
いま苦しくなっているのは買い手か、売り手か
その人たちの損切りはどこにありそうか
```

## 初心者がやりやすい失敗

投げ売りや踏み上げの場面は、値動きが派手です。

そのため、初心者ほど次のように反応しやすくなります。

```text
大きく下がったから、まだ下がるはず
大きく上がったから、まだ上がるはず
急に戻したから、すぐ反転するはず
```

でも、ここで大切なのは方向を当てることではありません。

大切なのは、**反応する前に一度待つこと** です。

投げ売り直後に底を当てに行くと、まだ下落が続くことがあります。  
急落直後に売ると、今度は踏み上げに巻き込まれることがあります。

値動きが速い場面ほど、感情も速くなります。だからこそ、ルールをシンプルにしておく必要があります。

## STOP、WAIT、CHECKで考える

ブログ教材では、次の3つに分けて見るとわかりやすいです。

| 表示 | 意味 | 行動 |
|---|---|---|
| STOP | 反応したくなる場所 | すぐ入らない |
| WAIT | 値動きを確認する場所 | 待つ |
| CHECK | 条件を確認する場所 | 損切り位置と上位足を見る |

たとえば踏み上げを狙うなら、急落そのものは `STOP` です。

```text
急落した
みんながまだ下がると思っている
でもここではすぐ売らない
```

そのあと、安値を更新できずに小さなレンジを作るなら `WAIT` です。

```text
下がらない
売り手が少し苦しくなっている
でもまだ入らない
```

最後に、レンジ高値を抜けて、すぐレンジ内へ戻らないなら `CHECK` です。

```text
売り手の損切りが出やすい
ただし損切り位置が遠ければ見送る
上位足の方向も確認する
```

## 今日の観察ポイント

投げ売りと踏み上げを見るときは、次の一文だけ覚えておくと十分です。

> 価格が動いた方向ではなく、降参している側を見る。

投げ売りは、買い手の降参。  
踏み上げは、売り手の降参。

ローソク足で見るなら、こうです。

```text
投げ売り = 高値圏で上がらなくなり、安値を割る
踏み上げ = 安値圏で下がらなくなり、高値を抜く
```

派手な足が出た瞬間に入るのではなく、そのあとに誰が苦しくなっているのかを見る。

それだけで、チャートの見方はかなり変わります。
