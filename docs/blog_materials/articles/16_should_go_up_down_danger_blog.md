# 「もう上がるはず」と思ったら、直近安値を割った時の行動を先に決める

作成日: 2026-06-01  
用途: ブログ記事下書き

## この記事で伝えること

トレードで危ない言葉があります。

```text
もう上がるはず
もう下がるはず
```

この「はず」が出ているとき、チャートを見ているようで、実は期待を見ていることがあります。

## はず、は根拠に見えやすい

「もう上がるはず」と思うとき、何かしら理由はあります。

```text
下げ止まったように見える
サポートが近い
前もここで反発した
```

「もう下がるはず」も同じです。

```text
上値が重い
高値更新できない
抵抗線がある
```

問題は、理由があることではありません。

その理由が、反対の情報を無視させてしまうことです。

## はず、が出たら確認する

「はず」と思ったら、次を確認します。

```text
その根拠はチャートに出ているか
否定されたらどこで切るか
反対方向の情報はないか
待てばもっと良い位置になるか
```

この確認ができないなら、まだ期待が強い状態です。

期待が強い状態で入ると、逆行したときに損切りが遅れます。

## 今日の観察ポイント

「もう上がるはず」「もう下がるはず」は、悪い言葉ではありません。

でも、そのままエントリー理由にするのは危険です。

> はず、が出たら一度止まる。

その期待がチャートで確認できるかを見る。  
確認できなければ、まだ入らない。

これだけで、希望で持つトレードは減ります。
