# 「置いていかれる」と思った時ほど、損切り位置が遠くなっている

作成日: 2026-06-01  
用途: ブログ記事下書き

## この記事で伝えること

「今入らないと置いていかれる」。

この気持ちが出たとき、すでにチャート判断より感情が前に出ている可能性があります。

## 置いていかれたくない心理

チャートが急に動くと、人は未来の利益を想像します。

```text
ここから伸びるかもしれない
今ならまだ間に合う
入らなかったら後悔する
```

でも、この心理は飛び乗りを作ります。

入りたい理由が「利益を逃したくない」になっているときは、かなり危険です。

## どう止めるか

置いていかれたくないと思ったら、次を確認します。

```text
損切り位置はどこか
今入らなくても次の候補はあるか
抜けた後に戻らない確認はあるか
```

この3つに答えられないなら、まだ入る場所ではありません。

## 今日の観察ポイント

> 置いていかれたくない気持ちは、エントリー理由ではなくSTOPサイン。

その感情に気づけたら、もう一度チャートを見直すチャンスです。
