# また同じ場所で負ける人は、負けたローソク足の直前を記録していない

作成日: 2026-06-01  
用途: ブログ記事下書き

## この記事で伝えること

何度も違うトレードをしているようで、実は同じ場所で負けていることがあります。

通貨や日時は違っても、心理の形が同じなのです。

## 同じ場所とは何か

同じ場所とは、価格が同じという意味だけではありません。

```text
抜けた瞬間
急落の途中
高値圏の飛び乗り
安値圏の追い売り
ローソク足1本判断
```

こうした「同じ心理が出る場所」です。

## 記録すべきこと

負けた後は、通貨やpipsだけでなく、次を記録します。

```text
なぜ入りたくなったか
待つ余地はあったか
損切り位置は見えていたか
前にも似た形で負けていないか
```

これを見ると、自分の負け方の型が見えてきます。

## 今日の観察ポイント

> 同じ失敗は、同じチャートではなく同じ心理で起きる。

負けた場所を、価格ではなく心理で分類してみてください。
