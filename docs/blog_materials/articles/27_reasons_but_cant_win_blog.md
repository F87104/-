# 根拠があるのに勝てない人は、後から増やした根拠で入っている

作成日: 2026-06-01  
用途: ブログ記事下書き

## この記事で伝えること

根拠を書いている。  
水平線も見ている。  
上位足も見ている。

それなのに勝てない。

この場合、根拠の数ではなく、根拠の質を見る必要があります。

## 根拠が多くても早いことがある

根拠が多いと安心します。

でも、根拠をたくさん並べても、エントリーが早ければ負けることがあります。

```text
節目がある
トレンド方向
ローソク足も強い
でも押し戻りを待っていない
```

この場合、根拠はあるけれど、確認が足りません。

## 根拠は入口と出口で見る

良い根拠は、入る理由だけではありません。

```text
入る理由
入らない理由が消えたこと
違ったときの撤退位置
```

この3つがそろうと、根拠の質が上がります。

## 今日の観察ポイント

> 根拠があることと、待てていることは別。

根拠の数を増やすより、どの確認を待ったかを見直してみてください。
