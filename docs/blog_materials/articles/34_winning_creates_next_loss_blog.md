# 勝ったのに、次の負けを作っていませんか？

作成日: 2026-06-01  
用途: ブログ記事下書き

## この記事で伝えること

負けたトレードだけが反省材料ではありません。

勝ったトレードも、次の負けを作ることがあります。

## 危険な勝ち

危険なのは、ルール外でも勝ってしまったトレードです。

```text
早く入ったけど勝てた
損切り位置が曖昧でも勝てた
根拠が弱くても伸びた
```

この経験は、次のトレードで判断を甘くします。

## 勝ちも分類する

勝ちトレードは、次の2つに分けます。

```text
再現してよい勝ち
たまたま助かった勝ち
```

利益が出たかどうかだけで判断しないことが大切です。

## 今日の観察ポイント

> 勝ったトレードほど、再現してよい勝ちかを確認する。

勝ちをそのまま自信に変える前に、プロセスを見直してみてください。
