# 「もう上がるはず」と思った時ほど危ない

作成日: 2026-06-01  
用途: ブログ記事下書き

## この記事で伝えること

「もう上がるはず」。

そう思った時ほど、確認が必要です。

## はず、は期待

「はず」という言葉には、期待が入っています。

```text
ここまで下げたから上がるはず
サポートだから上がるはず
下ヒゲが出たから上がるはず
```

でも、期待は根拠とは違います。

## 確認すること

「上がるはず」と思ったら、次を見ます。

```text
実際に高値を切り上げたか
安値を守ったか
損切り位置は近いか
```

確認がなければ、まだ期待の段階です。

## 今日の観察ポイント

> 「はず」が出たら、チャートで確認できるまで待つ。

期待を否定するのではなく、確認に変えることが大切です。
