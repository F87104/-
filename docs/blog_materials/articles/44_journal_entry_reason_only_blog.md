# トレード日誌に「なぜ入ったか」だけ書くと、見送る条件が残らない

作成日: 2026-06-01  
用途: ブログ記事下書き

## この記事で伝えること

トレード日誌に「なぜ入ったか」を書くことは大切です。

でも、それだけでは足りません。

本当に大事なのは、入る前の心理と、入らない理由です。

## 書きたい項目

日誌には次も書きます。

```text
入る前に焦りはあったか
置いていかれたくなかったか
損切り位置はどこだったか
入らない理由は残っていなかったか
```

これを書くと、失敗の型が見えやすくなります。

## 理由は後から増やせる

エントリー理由は、後から増やせます。

でも、入る前の感情はその時しか記録できません。

だから、日誌には感情も書きます。

## 今日の観察ポイント

> 日誌に書くべきは、理由だけでなく入る前の気持ち。

そこに、次の改善のヒントがあります。
