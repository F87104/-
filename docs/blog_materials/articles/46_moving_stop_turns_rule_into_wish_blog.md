# 損切り位置をずらした瞬間、トレードはルールから願望に変わる

作成日: 2026-06-01  
用途: ブログ記事下書き

## この記事で伝えること

最初は決めていたはずです。

```text
ここを割ったら切る
このラインを超えたら違う
ここまで来たら損切りする
```

でも、実際に価格がそこへ近づくと、少しだけ損切り位置をずらしてしまう。

この瞬間、トレードはルールではなく願望に変わります。

## 損切り位置をずらす心理

損切り位置をずらすとき、人はだいたいこう考えています。

```text
もう少しだけ待てば戻るかもしれない
ここで切ったら底かもしれない
さっきの根拠はまだ残っているかもしれない
この損失を確定したくない
```

どれも自然な気持ちです。

でも、ここで起きているのは、チャート判断ではなく損失を避けたい気持ちです。

## 最初の損切り位置には意味があった

エントリー前に決めた損切り位置は、ただの数字ではありません。

そこには、最初のシナリオがあります。

```text
ここを割ったら買いの根拠が崩れる
ここを超えたら売りの根拠が崩れる
ここまで逆行したら想定と違う
```

つまり、損切り位置は「負けを認める場所」ではなく、**シナリオが違ったと確認する場所** です。

その位置をずらすということは、最初のシナリオが崩れた後も、別の理由を探し始めるということです。

## ずらした後は根拠が変わる

損切り位置をずらした後、人は新しい根拠を探します。

```text
もう少し下にサポートがある
上位足ではまだ崩れていない
長いヒゲになるかもしれない
ここまで来たら反発しそう
```

この根拠が最初からあったなら、まだ検討できます。

でも、損切りが近づいてから出てきた根拠なら、それは後付けかもしれません。

後付けの根拠は、トレードを守っているようで、実際には損失を守っているだけのことがあります。

## 損切りをずらすと何が起きるか

損切りをずらすと、トレードのルールが崩れます。

```text
最初の損切り位置を超える
-> まだ耐える
-> 損失が大きくなる
-> さらに切りにくくなる
-> 祈りになる
```

損失が大きくなるほど、人は切りにくくなります。

最初の小さなずらしが、次の大きな迷いを作ります。

## ずらしてよい場合と、ずらしてはいけない場合

すべての損切り移動が悪いわけではありません。

利益方向に進んだ後、リスクを減らすために損切りを建値や有利な位置へ動かすことはあります。

危険なのは、**損失方向へ損切りを遠ざけること** です。

| 移動 | 意味 |
|---|---|
| 利益方向へ近づける | リスクを減らす |
| 損失方向へ遠ざける | 間違いを認める場所を先延ばしにする |

この記事で問題にしているのは、後者です。

## ずらしたくなった時の確認

損切り位置をずらしたくなったら、次の3つを確認します。

```text
1. その根拠はエントリー前からあったか
2. シナリオが崩れた事実を見ていないか
3. 損失を確定したくないだけではないか
```

この3つに正直に答えるだけで、かなり冷静になれます。

特に大事なのは1つ目です。

エントリー前から決めていた根拠ならルールです。  
損切り直前に出てきた根拠なら、願望の可能性があります。

## 今日の観察ポイント

損切り位置をずらしたくなる瞬間は、トレードの分岐点です。

そこでルールに戻るのか。  
願望に変わるのか。

この差は大きいです。

> 損切り位置を損失方向へずらした瞬間、最初のトレードは終わっている。

そこから先は、別のトレードです。

もし本当に続けるなら、最初から新しい根拠、新しい損切り位置、新しいリスクで入り直す必要があります。

ただ、ほとんどの場合は、最初に決めた場所で切る方がシンプルです。
