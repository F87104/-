# ブログ記事テンプレート

## タイトル

例: ブレイクした瞬間に入ると負けやすい理由

## この記事で伝えること

- 読者の悩み:
- チャートで起きている心理:
- 今日の結論:

## 1. よくある場面

例:

```text
抵抗線を上に抜けた
強い陽線が出た
このまま伸びそうに見えた
だからすぐ買った
```

## 2. そこで起きている心理

ここには、焦り、期待、取り逃がしたくない気持ちがある。

## 3. ローソク足で見るポイント

- どこを抜けたのか
- 抜けた後に戻らなかったか
- 押し戻りを待ったか
- 損切り位置は近いか

## 4. STOP / WAIT / CHECK

| 表示 | 意味 | 行動 |
|---|---|---|
| STOP | 反応したくなる場所 | 入らない |
| WAIT | 値動きを確認する途中 | 待つ |
| CHECK | 待った後の候補 | 損切り位置と上位足を確認 |

## 5. まとめ

今日の観察ポイント:

> 抜けた瞬間ではなく、抜けた後に戻らない時間を見る。
