## 連載の軸

この連載は、勝てるサインを配るためではなく、読者が自分のチャート判断を見直すための教材にする。

中心メッセージ:

> 失敗している人の逆をやるとは、売買方向を逆にすることではない。  
> 反応を遅らせ、確認を増やし、損切り位置を先に決めること。

## 記事テンプレート

1. 読者が経験しやすい悩みを書く
2. チャート上で起きている群衆心理を説明する
3. ローソク足や節目の見方を1つだけ示す
4. やってはいけない反応を `STOP` として書く
5. 待つべき状態を `WAIT` として書く
6. 確認する条件を `CHECK` として書く
7. 最後に「今日の観察ポイント」を1つ置く

## ブログで使いやすい表現

| 研究用語 | ブログ向け表現 |
|---|---|
| 節目抜け・ブレイク飛び乗り | 抜けた瞬間に飛び乗る |
| ロスカット巻き込み | 負けている側の損切りが燃料になる |
| Squeeze | 売り手が苦しくなって買い戻す |
| Capitulation | 買い手が耐えられず投げる |
| STOP | 今すぐ入らない場所 |
| WAIT | まだ待つ場所 |
| CHECK | 最後に確認する場所 |
