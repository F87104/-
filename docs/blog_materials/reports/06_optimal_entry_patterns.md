# トレード心理研究: 最適エントリーパターン抽出

## 研究の仮説

資料が豊富にあるため、失敗パターンだけでなく、エントリーに適したパターンも読める可能性が高い。
ただし「最適」は1つの形ではなく、環境認識、節目、待ち方、損切り位置、心理状態がそろった場所として定義する。

重要な方向転換:

- 1人の失敗だけを見るのではなく、複数の受講生が同じようなチャート形状で入っている場所を探す
- 複数人が反応する場所には、人間がそう見てしまう理由がある
- その場所を `STOP`、待った後の良い場所を `CHECK` としてPineに落とす

関連ノート:

- [受講生エントリー集中パターン研究](student_entry_cluster_research_2026-05-31.md)

## 失敗研究から成功研究へつなぐ考え方

失敗している人の逆をそのまま売買方向の反対にするのではなく、次のように変換する。

| 失敗の入り方 | 成功候補への変換 |
|---|---|
| 抜けた瞬間に飛び乗る | 抜けたあと、押し戻り・再停滞・再加速を待つ |
| レンジ中央の急変に反応する | レンジ端またはレンジ外定着を待つ |
| ローソク足1本だけで判断する | 節目、上位足、次足確認など追加根拠を待つ |
| 損切り位置が曖昧なまま入る | 入る前に否定ラインを決める |
| 感情で取り返そうとする | 入らない理由が消えるまで待つ |

## 抽出する構造化データ

今後は各トレードを、失敗・成功の両方で同じ列にそろえる。

| 項目 | 内容 |
|---|---|
| 匿名ID | 個人を特定しない研究用ID |
| ケースID | チャートまたは報告単位のID |
| 通貨ペア | 取引対象 |
| 時間足 | H1、H4など |

| 環境認識 | 上昇、下降、レンジ、転換候補 |
| 節目タイプ | 高安値、レンジ端、水平線、MA、上位足節目 |
| エントリー型 | 抜け再確認、押し戻り、レンジ端反発、レンジ外定着、転換確認 |
| 入る直前の確認 | 次足確認、戻り確認、再加速、否定ライン明確化 |
| 損切り根拠 | 直近高安値、節目割れ、シナリオ否定 |
| 感情 | 焦り、冷静、待てた、不安、取り返したい |
| Saiフィードバック | 改善に使える指摘だけを要約 |
| 成功パターン | 再現できる短いルール |
| 失敗パターン | 同じ形で負けた場合の注意点 |

| 信頼度 | 高、中、低 |

## 一次抽出 v0.1

匿名化済みの705トレードから、エントリー根拠文を中心にキーワード一次分類を行った。
これは結論ではなく、目視確認前の候補抽出である。

対象:

- 全トレード: 705件
- 結果既知: 537件
- 利益/利確: 247件
- 高信頼の利益/利確: 224件
- 結果既知全体の勝率: 46.0%

一次分類結果:

| エントリー型候補 | 利益/利確 | 損失/撤退 | 不明 | 既知勝率 |
|---|---:|---:|---:|---:|
| E01 節目抜け後の再確認 | 100 | 127 | 79 | 44.1% |
| E02 レンジ外定着 | 25 | 28 | 26 | 47.2% |
| E03 レンジ端反発 | 9 | 15 | 8 | 37.5% |
| E04 押し戻り継続 | 98 | 92 | 59 | 51.6% |
| E05 転換確認 | 65 | 69 | 42 | 48.5% |

一次結論:

- 成功候補は単独条件ではなく、複数条件の重なりとして出ることが多い
- E01は「抜けた事実」だけでは弱く、抜け後の停滞、押し戻り、2回目以降の確認が必要
- E04は全体平均より少し良く、押し戻り継続は成功候補として優先して見る価値がある
- E05はV字やヒゲ単体では危険で、節目、次足確認、否定ラインをセットにした時だけ候補になる
- 良い候補には「抜け」「停滞」「2回目以降」「上位方向」「撤退基準」が重なりやすい

## 細かい気づき v0.1

今回の目的は、すぐに売買ルールを固定することではなく、資料から判断の癖を発見すること。
以下は、成功候補と失敗候補を比較して見えてきた小さな気づきである。

### エントリー直前の気づき

- 「抜け」は入口ではなく、観察開始の合図に近い。勝ち候補では、抜けたあとに停滞、もみ合い、2回目以降の確認が出てから入る例が多い。
- 成功候補の中心は、派手な急騰急落ではなく「抜けた後に値が戻らない時間」である。つまり、勢いより定着を見る。
- 失敗側は、値動きの速度に反応しやすい。成功側は、値動きの後に残った形を見る。
- 「2回目以降」は重要だが、それだけで安全ではない。1回目を見送り、2回目で停滞や再加速がある時に意味が出る。
- 良いエントリーは、入る理由より先に「入らない理由が消えている」ことが多い。

### 心理の気づき

- 失敗側は「ここから伸びそう」という未来への期待が強い。成功側は「ここを割ったら違う」という否定条件が見えている。
- 焦りは、チャート上では「抜けた瞬間」「急落急騰の途中」「V字の最初」に出やすい。
- 冷静さは、チャート上では「停滞を待つ」「2回目を待つ」「レンジ外で確認する」として現れる。
- 勝っているトレードにも迷いは残っている。成功と失敗を分けるのは、感情がないことではなく、感情があっても撤退基準へ戻れること。
- 「慎重なエントリー」と書かれていても、実際には根拠が多いだけで早い場合がある。根拠の数と待てたかどうかは分けて見る。

### 失敗の逆利用に関する気づき

- 失敗している人の逆をやるとは、売買方向を逆にすることではない。反応を遅らせ、確認を増やすこと。
- 「飛び乗り」の逆は「見送る」ではなく、「抜け後の停滞を待つ」である。
- 「レンジ中央の急変」の逆は「反対売買」ではなく、「レンジ端かレンジ外まで判断を保留する」である。
- 「V字・ヒゲ単体」の逆は「無視」ではなく、「追加根拠が2つ以上そろうまで観察対象に留める」である。
- 「損切り遅れ」の逆は、損切りを浅くすることではなく、入る前にシナリオ否定位置を決めること。

### 成功候補の注意点

- 利益/利確になっていても、良いプロセスとは限らない。利益になった早すぎるエントリーは、成功パターンではなく危険な成功体験として扱う。
- 成功候補には、良い入口と弱い出口が混ざっている。エントリー研究と決済研究は分けて見る必要がある。
- 「V字」「ヒゲ」「ブレイク」は成功例にも失敗例にも出る。差を作るのは、その形が節目、時間足、停滞、否定ラインと組み合わさっているか。
- 条件を増やしすぎると、後から都合よく説明できてしまう。Pine化するときは、まず3条件までに絞る。
- 今の段階では、正解パターン探しではなく「判断が崩れる場所」と「判断が整う場所」の比較が重要。

## 群衆心理検出器 v0.2

上記の気づきを、TradingViewで目視できるPine可視化ツールに変換した。

- [pine/visual/crowd_psychology_detector_visual.pine](../../pine/visual/crowd_psychology_detector_visual.pine)
- シンプル版: [pine/visual/crowd_psychology_simple_visual.pine](../../pine/visual/crowd_psychology_simple_visual.pine)

検出器の役割:

| 表示 | 意味 | 研究上の見方 |
|---|---|---|
| FOMO | 節目抜け直後の飛び乗り | 抜けは入口ではなく観察開始 |
| PANIC | レンジ中央の急変反応 | 速度ではなく、レンジ端/外側まで待つ |
| WICK | ヒゲやローソク足1本判断 | 単体ではなく追加根拠2つを確認 |
| WAIT | 抜け後の押し戻り/再停滞後の候補 | 反応を遅らせた場所 |
| OUT | レンジ外定着 | レンジ内に戻ったら撤退できる場所 |
| PB | 押し戻り継続 | 伸び切りではなく再開位置 |

表示方針:

- 赤/橙/紫は「群衆心理が動きやすい場所」
- 緑は「待てた候補」
- 緑サインには点線で否定ライン候補を出す
- V字やヒゲは単体では緑サインにしない
- 売買サインではなく、研究用の観察補助として使う

v0.2表示改善:

TradingViewで確認したところ、v0.1は `WICK` と `PB` が多く、ローソク足を読む邪魔になりやすかった。
研究の初期確認では、まず「抜け直後の反応」と「待てた候補」に集中する。

- `WICK` は初期OFFに変更
- `PB` は初期OFFに変更
- 状態テーブルは初期OFFに変更
- 否定ライン候補は初期OFFに変更
- 同じ種類の表示間隔を12本から24本へ変更
- `WICK` 条件を厳格化し、強いヒゲだけを対象に変更
- `PB` はレンジ中を除外し、確認足の実体比率を追加

おすすめの見方:

1. 初期状態では `FOMO`、`PANIC`、`WAIT/OUT` だけを見る
2. チャートが読める状態になってから `WICK` をONにする
3. トレンド中の押し戻り研究をしたい時だけ `PB` をONにする
4. 教材化する場面だけ、状態テーブルと否定ラインをONにする

## シンプル運用 v0.1

複雑になりすぎたため、リアルタイムでは3つだけを見る。
研究用の細かい分類は残すが、実際の画面では `STOP`、`WAIT`、`CHECK` に集約する。

| 表示 | 意味 | 行動 |
|---|---|---|
| `STOP` | 反応しやすい場所 | 入らない |
| `WAIT` | 確認中 | 待つだけ |
| `CHECK` | 待ったあとの候補 | 上位足と損切り位置だけ確認 |

シンプル版のルール:

- 赤い `STOP` が出たら、その足では入らない
- 黄色い `WAIT` は、まだ入る場所ではなく観察だけ
- 緑の `CHECK` が出た時だけ、候補として見る
- `CHECK` でも、損切り位置が見えないなら入らない
- 記録は「STOPで待てたか」「CHECKまで待てたか」だけを見る

これにより、リアルタイムの目的を次の1つに絞る。

> 飛び乗らず、待った後だけ確認する

## TradingView観察 v0.2: GBPJPY H1

v0.2をGBPJPY H1に貼った結果、v0.1よりも主信号の関係が見やすくなった。
特に `FOMO`、`PANIC`、`WAIT` の並びから、失敗側と成功候補側の差が見える。

観察できたこと:

- `FOMO` は高値/安値の抜け直後や伸びた先に出やすい。ここは「今すぐ入る場所」ではなく、群衆が反応しやすい観察開始点として扱う。
- `FOMO` のあとにすぐ反転・停滞・乱高下する箇所があり、抜けた瞬間の飛び乗りは失敗教材になりやすい。
- `WAIT` は、抜けたあとに押し戻りや再確認が入った場所に出ており、失敗側の反応を遅らせた候補として見やすい。
- `PANIC` はレンジ中央や急変後に出やすく、その後は一方向に伸びるよりも戻り・停滞・乱高下が混ざる。ここは売買方向を当てる場所ではなく、保留ゾーンとして扱う。
- 下方向の `FOMO` は、下抜け成功ではなく、すでに伸び切った売り反応として出る場面がある。安値側では、さらに `OUT` や戻り確認がなければ追いかけない。
- 右側の値動きでは、`PANIC` や下方向 `FOMO` のあとに価格が戻っており、ブレイク反応だけで売ると捕まりやすい形が見える。

この画像からの暫定結論:

- 失敗している人の逆をやるとは、`FOMO` の逆方向に入ることではない。
- 重要なのは、`FOMO` や `PANIC` の直後に反応せず、次の `WAIT`、`OUT`、または明確な再確認まで待つこと。
- 成功候補は「抜けた方向」よりも、「抜けたあとに戻らない時間」「押し戻り後の再加速」「入る前の否定ライン」で判断する。
- `FOMO` と `PANIC` が近い間隔で出る場所は、群衆心理が強く動いているため、エントリー候補ではなく観察・見送り候補にした方がよい。

詳細版で保留する改善:

- `FOMO` を「継続ブレイク候補」と「伸び切り飛び乗り注意」に分ける
- `FOMO` 後の一定本数を観察ゾーンとして薄く表示する
- `PANIC` が出た場所を、エントリー候補ではなく保留ゾーンとして明確化する
- `WAIT` は、押し戻り後の再加速、節目外維持、EMA方向一致の重なりを強める
- 安値/高値側の `FOMO` は、レンジ外定着がなければ追いかけ注意にする

## リアルタイム運用への落とし込み v0.2

この検出器は売買サインではなく、リアルタイムで「反応してしまう場所」を見つけるための補助にする。
実運用では、分類を増やさず、3段階だけで判断する。

基本方針:

| 表示 | リアルタイムでの扱い | 行動 |
|---|---|---|
| `STOP` | 反応禁止 | 入らない |
| `WAIT` | 観察中 | 待つだけ |
| `CHECK` | 候補 | 上位足と損切り位置だけ確認 |

リアルタイム手順:

1. `STOP` が出たら入らない
2. `WAIT` が出ても入らない
3. `CHECK` が出た時だけ候補として見る
4. 上位足の方向と損切り位置が見えなければ見送る
5. 結果を1行だけ記録する

エントリー候補にしてよい最低条件:

- 上位足の方向、またはレンジ外定着と矛盾していない
- `STOP` の直後ではなく、`WAIT` か `CHECK` まで待っている
- レンジ中央ではなく、節目付近、レンジ端、またはレンジ外で判断している
- 入る前に、シナリオが否定される価格が見えている
- 連敗後、取り返したい感情、焦りがある場合は入らない

リアルタイム判定:

| 判定 | 行動 |
|---|---|
| `STOP` | 入らない |
| `WAIT` | 待つ |
| `CHECK` | 確認する |

リアルタイムで記録する列:

| 項目 | 内容 |
|---|---|
| 時刻 | サインが出た時刻 |
| 通貨ペア/時間足 | 例: GBPJPY H1 |
| 表示 | STOP、WAIT、CHECK |
| 感情 | 入りたい、待てた、迷ったなど |
| 行動 | 入らない、待つ、確認する、見送る |
| 結果 | 伸びた、戻った、レンジ化など |
| メモ | 1行だけ |

記録テンプレート:

- [realtime_trade_psychology_log_template.csv](realtime_trade_psychology_log_template.csv)

リアルタイム用の注意:

- これは投資助言ではなく、研究用の意思決定プロトコルである
- レバレッジを使うFXでは、急変時に損失が大きくなる可能性がある
- 検出器の勝率を確認するまでは、実資金ではなくデモまたは極小ロットで検証する
- まずは「勝てたか」よりも「STOPで入らず待てたか」を評価する

## 検証方法

1. 成功トレードだけを先に集めず、失敗トレードと同じ条件で並べる
2. エントリー後の結果を見てから理由を作らないよう、入る直前に見えていた情報だけを書く
3. 同じチャート形状で、勝った例と負けた例をペアにする
4. 勝った例に共通していて、負けた例に欠けている条件を探す
5. 条件が言語化できたものだけPine候補にする
