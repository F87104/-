### 現状サマリー

### 検証で明らかにしたいこと

1. **H4 `ihs_5pivot + context` は他の7銘柄でも機能するか**
2. **NAS100・XAUUSD・XAGUSD など非JPY銘柄での波形特性**
3. **TradingView H4 データとローカルCSVデータの整合性**
4. **精度向上フィルタ候補**（ADX方向一致 / 上位足D1コンテキスト / 日時フィルタ）

### 検証設計

#### Step 1: TradingView目視確認（Pine視覚化）

> Pine: `synapse_mtf_wave_reversal_v4.pine` をH4に載せる

各銘柄で以下を目視確認：

| チェック項目 | 合格基準 |
|---|---|
| 中波の緑線が「人が見て納得できる波」に重なるか | 主要な押し・戻りに合っている |
| `P0/P1/P2` が中波2波の終端付近に出るか | 伸び切った後に出ない |
| A/Bラインが役割線として機能しているか | 最大最小ではなく圧力線・確認線 |
| Bブレイク後に伸びる場面で候補が出るか | 乗り遅れサインが少ない |

記録: `docs/research/Synapse_目視記録_8通貨.md`（新規作成）

#### Step 2: 8通貨バックテスト拡張

既存の `backtests/synapse_v2_definition_grid/` を8通貨に拡張。

| パラメータ | 設定 |
|---|---|
| 時間足 | **H4 メイン**（M15 補助確認） |
| 構造 | `ihs_5pivot`（メイン）/ `classic_6pivot`（精度確認用） |
| フィルタ | `context` / `diag_break` |
| TP | 固定2R / 固定1.5R / 半値 |
| IS期間 | 2015-01-01 〜 2024-12-31 |
| OOS期間 | 2025-01-01 〜 現在 |

成功条件: **PF ≥ 1.5 / DD ≤ Total R の 1/3 / OOS再現** を3通貨以上で確認

#### Step 3: 精度向上フィルタの追加検証

有望フィルタ（優先順）:

| # | フィルタ | 仮説 |
|---|---|---|
| F1 | D1方向一致（D1 EMA or D1トレンド） | 上位足と順行する2波のみ拾う |
| F2 | ADX ≥ 20（中波1波の強度確認） | 弱いトレンドからの反転は除外 |
| F3 | 中波2波の時間フィルタ（1波時間 × 0.5以上） | 浅い調整は除外 |
| F4 | ヘッド/右肩の実体比率 ≥ 0.35 | ヒゲ主体の反転は低品質 |

## 両研究の共通ルール

1. **TradingView データを正とする** — ローカルCSVとずれがある場合はTV優先
2. **H4 メイン** — 両研究ともH4で先行検証し、機能すればH1へ展開
3. **目視確認必須** — バックテスト数字だけで採用しない。人間が見て納得できるかを確認
4. **OOS再現を本番採用の条件にする** — IS好成績のみでは採用しない
5. **フォワード記録を続ける** — v2.1は30件、Synapseは採用検討前に20件
