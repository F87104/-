# B7棚 — パラメータ解説（Pine設定画面の項目ごと）

> 設定画面に表示される**全パラメータ**を、1つずつ「何を見ているか」「なぜこの値か」「変えるとどうなるか」で解説。

---

## 全体像（これだけ覚えればOK）

```
急落した → 戻った → 横ばいした → 棚を上抜けた → 買い
```

この5ステップの**各判定基準**がパラメータ。

---

## 共通グループ

### H4チャートのみ売買 `requireH4` ✅ON
**何を見ているか**: チャートの時間足が4時間足かどうか。
**なぜ**: B7棚はH4で検証した手法。H1やD1では棚の意味が変わるため、誤動作防止。
**変えると**: OFFにすると任意の時間足で動作するが、未検証なので非推奨。

### 2015〜2026のみ `useDate` ✅ON
**何を見ているか**: 売買をバックテスト対象期間に限定。
**なぜ**: 2015年以前のデータは信頼性が低い場合がある。
**変えると**: OFFにすると全期間でトレード。件数は増えるが古いデータの影響を受ける。

### ATR期間 `atrLen` = 14
**何を見ているか**: ATR（平均値幅）を計算する期間。
**なぜ**: 14は業界標準。「直近14本の平均的な値動き幅」を1ATRとして、全てのパラメータの基準に使う。
**変えると**: 大きくすると鈍感（長期の平均）、小さくすると敏感（直近の変動に追従）。基本的に変更不要。

### タイムアウト有効 `useTimeout` ✅ON
**何を見ているか**: 一定期間経過後に強制決済するかどうか。
**なぜ**: SLにもTPにも到達しない「塩漬け」ポジションを防止。
**変えると**: OFFにするとSL/TPに当たるまで無期限保有。長期トレンドに乗りたい場合はOFF。

### 最大保有(本) `maxHold` = 60
**何を見ているか**: エントリーから何本後に強制決済するか。
**なぜ**: H4で60本 = 約10日間。スイングトレードとして妥当な期間。
**変えると**: 短くすると「早めに見切り」、長くすると「粘る」。15本(2.5日)〜120本(20日)で銘柄による。

---

## ★銘柄プリセット

### プリセット選択 `preset`
**何を見ているか**: 選択した銘柄に最適なRR/急落/棚幅/SL/TIMEを自動設定。
**なぜ**: 銘柄ごとに最適なパラメータが異なる（ゴールドは急落が大きい等）。
**注意**: 棚の本数だけは手動変更が必要（XAUUSD→3、EURJPY/USDJPY→5、他→7）。

## V Shelf 条件（エントリー判定の核心）

### 急落の参照窓(本) `dropLook` = 24
**何を見ているか**: 「急落があったか」を過去何本さかのぼって確認するか。

```
←─── 24本（約4日間）───→ ←棚→ ←今
■■■■■■■■■■■■■■■■■■■■■■■■ ■■■■  ▲ブレイク
この窓の中に急落があったか？
```

**なぜ24本**: H4で24本 = 4日間。急落→回復→棚形成のサイクルとして妥当。
**変えると**: 大きくすると古い急落も拾える（件数増）、小さくすると直近の急落のみ（件数減・精度上）。

---

### 急落幅下限(ATR) `dropAtrMin` = 2.8
**何を見ているか**: 「急落」と見なす最低限の値幅。参照窓内の（最高値 − 最安値）がこの値以上か。

```
高値 ──╮
       │ ← この落差が 2.8ATR 以上？
       │    YES → 「急落あり」
安値 ──╯
```

**なぜ2.8**: 普段の値動き(1ATR)の約3倍。「明らかにいつもと違う大きな下落」を捉える閾値。
**変えると**:
- **大きく(3.5〜4.0)**: 本当に大きな急落だけ。件数減るがPF上がる傾向（ゴールドは4.0推奨）
- **小さく(2.0)**: 小さな下げも拾う。件数増えるがノイズ混入

---

### 回復率下限 `recMin` = 0.65 (65%)
**何を見ているか**: 急落後、どれだけ値段が戻ったか。

```
高値 ──╮         ┌── 棚安値がこの辺り
       │ 急落幅   │   (急落幅の65%〜125%戻し)
       │         │
安値 ──╯─────────╯
```

**計算**: (棚安値 − 急落安値) ÷ 急落幅
**なぜ0.65**: 少なくとも65%戻していれば「V字回復」と言える。底に張り付いたままは回復不足。
**変えると**: 大きくすると「しっかり戻った場合だけ」（精度上）、小さくすると「少し戻っただけでもOK」。

### 回復率上限 `recMax` = 1.25 (125%)
**何を見ているか**: 回復しすぎていないか。
**なぜ1.25**: 急落幅の125%以上戻ったら、もう棚ではなく上昇トレンドの途中。別の手法の領域。
**変えると**: 基本的に変更不要。

---

### 棚の本数 `shelfBars` = 7
**何を見ているか**: 「横ばい」と判定するローソク足の本数。直近N本が横ばいかどうか。

```
      ┌──────────────────────┐
      │  7本間で値動きが小さい  │ ← これが「棚」
      │  ＝横ばい・レンジ       │
      └──────────────────────┘
                              ↑ ブレイク！
```

**なぜ7本**: H4で7本 = 約28時間（1.2日間）。「翌日まで崩れなかった」= 売り手が諦めた証拠。
**変えると**:
- **3本(12時間)**: 短い棚。ゴールドは3が最適（急落が激しく素早くブレイクする性質）
- **5本(20時間)**: USDJPY/EURJPYは5が最適
- **7本(28時間)**: その他の銘柄のデフォルト
- **10本以上**: 長すぎてブレイクを逃しやすい

---

### 棚幅上限(ATR) `shelfAtr` = 1.8
**何を見ているか**: 棚の中の値動きの許容幅。棚の（最高値 − 最安値）がこの値以下か。

```
棚高値 ─── ┐
           │ ← この幅が 1.8ATR 以下？
棚安値 ─── ┘    YES → 「十分に横ばい」
```

**なぜ1.8**: 普段の値動き(1ATR)の約2倍以内。これ以上広いと「横ばい」ではなく「乱高下」。
**変えると**:
- **小さく(1.2〜1.5)**: 非常にタイトな棚だけ。精度上がるが件数激減
- **大きく(2.0〜2.5)**: 緩い棚も許容。CHFJPYは2.5が最適

---

### 棚安値保持率 `shelfHold` = 0.4 (40%)
**何を見ているか**: 棚の安値が「急落から回復した位置」を維持しているか。

```
高値 ──╮
       │ 急落幅       ← 急落の40%ライン ───── holdLine
       │                ↑
安値 ──╯            棚安値がこれより上か？
```

**計算**: holdLine = 急落安値 + 急落幅 × 0.4
**なぜ0.4**: 急落幅の40%以上を維持していれば「棚が崩れていない」。底まで落ちてきたら棚の意味がない。
**変えると**: 大きくすると「高い位置を維持した強い棚のみ」、小さくすると「少し下がっても許容」。

---

### ブレイクバッファ(ATR) `breakBuf` = 0.05
**何を見ているか**: 棚高値をどれだけ超えたら「ブレイク」と判定するか。

```
棚高値 ───────── + 0.05ATR ← このラインを終値で超えたら判定
```

**なぜ0.05**: ATRの5%（わずかな余裕）。ちょうど棚高値ピッタリだとダマシが多いため、少し上で確認。
**変えると**: 基本的に変更不要。大きくするとブレイク判定が厳しくなる。

---

### ブレイク足実体下限 `minBody` = 0.30 (30%)
**何を見ているか**: ブレイクした足が「実体のある足」かどうか。

```
  │       ← 上ヒゲ
  ██      ← 実体（始値〜終値）= 足の値幅の30%以上？
  ██
  │       ← 下ヒゲ
```

**計算**: |終値 − 始値| ÷ (高値 − 安値)
**なぜ0.30**: 実体が30%以上あれば「しっかり買われた」証拠。ヒゲだけで抜けた足はダマシが多い。
**変えると**: 大きくすると「強いブレイク足のみ」（精度上）、0にすると何でもOK。

---

### ブレイク足終値位置下限 `minCLoc` = 0.50 (50%)
**何を見ているか**: ブレイク足の終値が足のどの位置にあるか。

```
高値 ─── 100%
         ← 終値がここ以上(50%以上)なら「強い引け」
中間 ─── 50%
         ← 終値がここ以下なら「弱い引け」= 除外
安値 ─── 0%
```

**計算**: (終値 − 安値) ÷ (高値 − 安値)
**なぜ0.50**: 足の上半分で引けていれば「買いが優勢のまま引けた」。下半分で引けた足は反転リスク。
**変えると**: 0.70にすると「足の上位30%で引けた強い足のみ」。

---

### SL余白(ATR) `stopBuf` = 0.25
**何を見ているか**: ストップロスを棚安値からどれだけ離すか。

```
棚安値 ─────────
       │ 0.25ATR ← この余白
SL ────┘          ← ここに損切りを置く
```

**なぜ0.25**: 棚安値ちょうどだと、ちょっとしたヒゲで刈られる。ATRの25%分の余裕を持たせる。
**変えると**:
- **小さく(0.10〜0.15)**: SLが近い。損切り額は小さいが刈られやすい。USDJPY/XAGUSDは0.15推奨
- **大きく(0.40〜0.50)**: SLが遠い。ヒゲに耐えるが、負けた時の損が大きい。CHFJPY/XAUUSD推奨

---

### 最大リスク幅(ATR) `maxRiskAtr` = 2.5
**何を見ているか**: エントリー価格からSLまでの距離が大きすぎないか。

**なぜ2.5**: リスク幅がATRの2.5倍を超えると、勝ってもRR的に割に合わない。安全装置。
**変えると**: 基本的に変更不要。大きくするとリスクの大きいトレードも許容。

---

## 表示グループ

### IN/OUTラベル `showInOut` ✅ON
エントリー時に「Long」、決済時に「Exit」のラベルを表示。

### Entry/SL/TP線＋損益R `showV1Style` ✅ON
保有中にEntry(黄色)/SL(赤)/TP(緑)のラインを表示。決済時に「+1.5R」等のR倍率を表示。

## パラメータ早見表

| パラメータ | 何を見ている | デフォルト | 大きくすると | 小さくすると |
|---|---|---:|---|---|
| 急落幅下限 | 急落の大きさ | 2.8 | 大急落のみ(件数減・精度上) | 小さい急落も拾う(件数増) |
| 回復率下限 | V字の戻り | 0.65 | しっかり戻った時だけ | 少しの戻りでもOK |
| 棚の本数 | 横ばい期間 | 7 | 長い横ばい確認(信頼性上) | 短い棚で素早く判定 |
| 棚幅上限 | 横ばいの幅 | 1.8 | ゆるい棚も許容 | タイトな棚のみ |
| 棚安値保持率 | 棚の崩れ具合 | 0.4 | 崩れてない強い棚のみ | 多少崩れても許容 |
| 実体下限 | ブレイク足の強さ | 0.30 | 強い足のみ | 弱い足もOK |
| 終値位置 | 引けの強さ | 0.50 | 上位引けのみ | 下位引けもOK |
| SL余白 | 損切りの余裕 | 0.25 | ヒゲ耐性上(損拡大) | タイト(刈られやすい) |
| 最大保有 | 保有期間 | 60 | 粘る | 早めに見切り |
