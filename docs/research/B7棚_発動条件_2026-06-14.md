# B7棚 — 発動条件

> **急落したけど、売りが失敗して上に戻り、しばらく崩れずに横ばいした後、棚の上を抜けた瞬間に買う。**
> V字の底を当てるのではなく、**売りの失敗を確認してから買う順張り**。

---

## 前提

- 時間足: **H4**
- 方向: **ロングのみ**
- Pine: `pine/research/b7_shelf_breakout_strategy.pine`

---

## 発動条件（5ステップ）

### ステップ1: 急落が起きる

直近24本（約4日間）の中で、**高値と安値の差が 2.8ATR 以上**の急落があること。

```
棚の前24本の（最高値 − 最安値）≥ 2.8 × ATR
```

---

### ステップ2: 急落が否定される（回復）

急落の後、価格が**急落幅の65%〜125%まで回復**していること。

```
（棚安値 − 急落安値）÷ 急落幅 = 65%〜125%
```

- 底で止まったまま＝回復不足（除外）
- 急落幅を完全に超えて上に行った＝もう棚ではない（除外）

---

### ステップ3: 上側で棚を作る（7本間）

回復した後、**直近7本（約1.2日間）で価格が横ばい**になること。

```
直近7本の（最高値 − 最安値）≤ 1.8 × ATR
```

さらに**棚の安値が急落幅の40%以上を維持**していること（棚が崩れていない）。

---

### ステップ4: 棚高値を終値でブレイク

```
前の足の終値 ≤ 棚高値
今の足の終値 ＞ 棚高値 + 0.05ATR（バッファ）
```

かつ**ブレイク足の品質チェック**：

| チェック | 基準 |
|---|---|
| 実体比率 | ≥ 30%（ヒゲだけのブレイクを除外）|
| 終値位置 | ≥ 50%（足の上半分で引けている）|

---

### ステップ5: リスク管理

| 項目 | 値 |
|---|---|
| **SL（損切り）** | 棚安値 − 0.25ATR |
| **TP（利確）** | SLからの距離 × RR（銘柄別自動）|
| リスク幅上限 | 2.5ATR以内（広すぎたら見送り）|
| 最大保有 | 60本（H4で約10日間）|

## 図解

```
      高値 ────╮
               │  ← ①急落（2.8ATR以上）
               │
      安値 ────╯
               ↑
           ②回復（65-125%）
               ↑
      ┌────────────────┐
      │  ③棚（7本間）    │ ← 値幅1.8ATR以内・崩れず横ばい
      │  安値━━━━━━━━━━━│
      └────────────────┘
                        ↑
                   ④終値で上抜け（実体30%以上・終値位置50%以上）
                        ↑
                   ⑤ Entry → SL=棚安値 / TP=RR×リスク幅
```

## 見送り条件

以下は見送る：

- H4以外の時間足
- 急落幅が2.8ATR未満（急落が弱い）
- 回復率が65%未満 or 125%超（回復不足 or 行き過ぎ）
- 棚幅が1.8ATR超（棚が広すぎ＝横ばいではない）
- 棚安値が急落幅の40%を維持できていない（棚が崩れている）
- ブレイク足の実体が30%未満（ヒゲブレイク）
- ブレイク足の終値位置が50%未満（足の下半分で引けた）
- SLまでの距離が2.5ATR超（リスクが大きすぎ）
- すでにポジション保有中

## 手法の本質

この手法の本質は、V字ではなく **急落否定後の上側滞在時間**。

急落後にすぐ戻しただけなら、まだただのショートカバーかもしれない。
しかし、戻した後に上側で崩れず棚を作るなら、**売りが失敗し、買いが主導権を取り返した可能性が高い**。

その棚を抜ける瞬間だけを狙う。

---

## ATR（Average True Range）とは

**ローソク足1本あたりの平均的な値動き幅**。「その銘柄の普段の値動き幅を1としたときの、相対的な大きさ」を表す。

B7棚で使うATRは **ATR(14) = 直近14本の平均値幅**。

### 銘柄ごとの1ATRの目安

| 銘柄 | H4の1ATR目安 | 「2.8ATR」の意味 |
|---|---|---|
| ドル円 | 約0.50円 | 1.4円の急落 |
| ポンド円 | 約0.80円 | 2.2円の急落 |
| ゴールド | 約30ドル | 84ドルの急落 |
| NAS100 | 約200pt | 560ptの急落 |

### なぜATRを使うか

「◯円の急落」ではなく「◯ATRの急落」と書くことで、**銘柄が違っても同じ条件で判断できる**。ドル円の1円とゴールドの1ドルでは意味が全く違うが、「2.8ATR」ならどの銘柄でも**「普段の約3倍の急落」**という同じ意味になる。

### B7棚の条件をATRなしで読み替えると

| 条件 | ATR表記 | ドル円（ATR≈0.50円）での意味 |
|---|---|---|
| 急落幅 | ≥ 2.8ATR | **1.4円以上の急落** |
| 棚幅 | ≤ 1.8ATR | **0.9円以内の横ばい** |
| SL余白 | 0.25ATR | **0.125円（12.5pips）** |
| ブレイクバッファ | 0.05ATR | **0.025円（2.5pips）** |
