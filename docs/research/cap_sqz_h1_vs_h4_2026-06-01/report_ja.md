# H1 vs H4 検証レポート

## 結論（先に）

| 質問 | 答え |
|------|------|
| あなたの「H1の方が良かった」は嘘？ | **嘘ではない**（手動・銘柄・件数少の可能性大） |
| 同じPine設定をH1に貼るとバックテストも良い？ | **いいえ**。CORE4で **H1はマイナス寄り、H4の方が明確に良い** |
| 本番はどちら？ | **ルール自動化なら H4 STRICT 推奨**。H1は要フォワード |

---

## なぜ感覚とデータがズレるか

1. **H1の「6本」= 6時間、H4の「6本」= 24時間**（同じ数字でも別物）
2. H1だとシグナルが **年36回**、H4だと **年3回**（ノイズが増える）
3. 手動では **全部入らない・2.5R・XAGだけ** など、検証より有利になりやすい
4. インジは **踏み上げ+投げ切り両方表示** → 見た目で良い場面だけ記憶しやすい
