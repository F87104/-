# 早めに損切りしないといけないパターン研究

作成日: 2026-06-06  
状態: **進行中**（アンカーケース1件から仮説整理）

## 研究の問い

どんな局面では、**予定SLの価格まで待たず**、または **含み益があるうちに** 早めに損切り（撤退）しないと、  
「良い負け」が「悪い負け」や「利益の全吐き出し」に変わるのか。

実運用で欲しい判断:

- 入る前: このパターンなら **SLを狭く／指標前は入らない**
- 保有中: **今すぐ切るべきサイン** は何か
- 決済後: なぜ予定SLより早く／遅く切ったかを分類できるか

## きっかけ（アンカーケース）

| 項目 | 内容 |
|---|---|
| 日誌 | [2026-06-03 XAUUSD 投げ切り → 損切り](../trade_diary/practice/entries/2026-06-03_xauusd_h1_alert_buy.md) |
| エントリー | 6/3 22:59 買い 50 @ 4446.71（投げ切りシグナル・アラート鳴動） |
| 予定SL | **4330**（頭の中のみ・**未発注**） |
| 最大含み益 | **+約50万円** |
| 決済 | 6/5 23:00 @ 4365.64（予定SLより手前で成行損切り） |
| 確定損益 | **-668,492円** |
| 背景 | **雇用統計**、利確せず、SL未発注 |

この1件で起きたこと:

1. 入口は心理ラベル単独（投げ切り）＋アラート音  
2. 一度は大きく勝てた（+50万）  
3. 利確ルールなし → 利益を全部返した  
4. SLは決めていたが置いていなかった  
5. 指標日まで保有 → 早めの**撤退**ではなく、結果的に**遅い損切り**

→ 「早めに損切り」の研究は、**狭いSLで切る**だけでなく、  
**含み益のうちに逃げる／指標前に降ろす／根拠否定で即切る** も含む。

## 仮説: 早めに切らないと化けるパターン（v0.1）

| ID | パターン名 | 典型の見え方 | 早めに切るトリガー（案） | 待ってはいけない理由 |
|---|---|---|---|---|
| **E01** | 投げ切り単独・反転未確認 | 青三角「投げ切り」だけ、棚・再ブレイクなし | エントリー後 **N本以内に安値更新** | [Capitulation直買いは単独保留](market_psychology_squeeze_strict_2026-05-30.md) と一致 |
| **E02** | アラート音トリガー | 形より音・通知で入った | エントリー直後から含み損／想定と違う動き | 確認ステップ（STOP→CHECK）を飛ばしている |
| **E03** | 頭の中SLのみ | 価格は決めているが逆指値未発注 | **否定ライン到達＝即成行**（SL価格を待たない） | 6/3ケース。予定4330より4365で切ったが、+50万後なので手遅れ |
| **E04** | 含み益の全返し型 | 一度 +X万 まで伸びた | 含み益が **ピークから -Y%**（例: -30〜50%）で全決済 | 6/3: +50万 → -66.8万。**最大の反省** |
| **E05** | 重要指標前のロング | 雇用統計・FOMC・CPI 等 | **指標の 2〜4時間前**に利益・建玉を整理 | 6/5 決済。ボラ拡大でSL以前にストーリー崩壊 |
| **E06** | ストーリー矛盾 | 同銘柄で逆方向シグナル（例: 投げ切り買い＋V1売り） | 逆シグナル点灯時点で **どちらか一方を閉じる** | 6/3 買いと 6/4 V1ショートが同時に存在 |
| **E07** | 下落トレンド中の底値拾い | 高値からの下落途中で「安そう」 | **直近安値を終値で割ったら即切** | 受講生つまずきの XAUUSD 天井買い系と同型 |
| **E08** | 否定後の希望保有 | 「戻るはず」で決済を遅らせる | 事前に書いた **否定条件** が1つでも成立したら即切 | [決済心理の地図](future_trade_psychology_research_themes_2026-05-31.md) の「希望保有」 |

## 「早めに切る」と「予定SLまで待つ」の境界

```
エントリー
   │
   ├─ 根拠否定（E01/E07/E08）──────→ 即撤退（SL価格を待たない）
   │
   ├─ 含み益ピークから Y% 戻し（E04）→ 利確 or 全決済
   │
   ├─ 指標まで T 時間（E05）────────→ 指標前に整理
   │
   ├─ 逆シグナル（E06）────────────→ 一方決済
   │
   └─ 上記なし ────────────────────→ 発注済みSL / TP で機械的に
```

**原則（v0.1）:**

1. **SLは必ず発注する**（頭の中SLは研究対象外にしない）
2. **早めに切る条件は、入る前に書く**（指標・含み益返し率・否定ライン）
3. 「早めに損切り」＝狭い損失ではなく、**ストーリー崩壊時の即撤退**も含む

- 既存4件を分類し、6/3 は **E01+E02+E03+E04+E05** の複合

### 段階2: 勝ち→負けの振れ幅

| 指標 | 定義 |
|---|---|
| MFE（最大含み益） | 保有中の最大プラス |
| MAE（最大含み損） | 保有中の最大マイナス |
| 返し率 | 確定損益 / MFE（MFE>0のとき） |

6/3: MFE ≈ +50万、確定 -66.8万 → **返し率 < -100%**（利益＋元本を吐き出し）

### 段階3: イベント研究

XAUUSD / 主要円ペアで、**雇用統計・CPI・FOMC** 前後24時間の  
「投げ切り系エントリー」の MFE/MAE を集計（Python または 手動サンプル10件）。

### 段階4: Pine 化（後回し可）

- 投げ切りマーカー + **「反転未確認」フィルタ**（棚なし・安値更新で警告）

- 含み益ピークからの **ドローダウン警告**（手動メモ用ラベルでも可）

## 実運用ルール候補（v0.1）

| # | ルール | 対応パターン |
|---|---|---|
| 1 | 投げ切り単独では入らない。棚 or 再ブレイクまで **WAIT** | E01 |
| 2 | アラート音だけでは入らない。**CHECK** 完了まで待つ | E02 |
| 3 | エントリー直後に **逆指値SLを必ず発注** | E03 |
| 4 | 含み益 **+20〜30万**（または +1R）で **一部利確** | E04 |
| 5 | 含み益がピークから **-30%** 戻したら **残り全決済** | E04 |
| 6 | **雇用統計・FOMC・CPI** の前日〜当日朝までに建玉ゼロ | E05 |
| 7 | 同銘柄で逆シグナル → **先に片方を閉じる** | E06 |
