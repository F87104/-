# H4 Double V Reclaim 研究メモ 2026-06-02

## 狙い

V字のあとに、もう一度V字を作る形を探す。

最初のVを直接買うのではなく、1回目のVを「売りが失敗した文脈」として使い、2回目のVで右肩が強くなったところを買う。

## 手法名

H4 Double V Reclaim

## ロジック

### V1

- confirmed pivot high から confirmed pivot low への急落
- 下落幅 >= 3.0 ATR
- 左肩速度 >= 0.20 ATR/本
- 左肩本数 2〜36本

### V2

- V1安値の後にできる次の confirmed pivot high -> confirmed pivot low
- 初期設定では V1 -> V2 を連続した `H-L-H-L` pivot に限定する
- V2開始高値が、V1下落幅の61.8%以上まで回復している
- V2開始高値のV1回復率は1.60以下
- V2開始高値を、V1右肩高値として扱う
- V1右肩高値が、V1左肩起点を0.05ATR以上上抜けている
- V1右肩速度 >= V1左肩速度 x 1.00
- V2安値が、V1の38.2%回復ラインを守っている
- V2下落幅 >= 1.4 ATR
- V2下落幅 / V1下落幅 >= 0.25
- V2左肩速度 >= 0.15 ATR/本
- V2左肩本数 >= 3本
- V2右肩速度 >= V2左肩速度 x 1.20
- V2右肩終値が、V1右肩高値を0.05ATR上抜け
- 実体比率 >= 45%
- 終値位置 >= 60%

### スクリーンショット共通点

2026-06-02 21:50前後に確認したGBPJPY H4の3例では、良く見える場所に以下の共通点があった。

- 形は単なるDouble Vではなく、`急落 -> V1反発 -> V2押し -> V1右肩高値突破`
- エントリー候補はV2の底ではなく、V2右肩がV1右肩高値を抜く場所
- V2はV1より小さく、浅い押しになっている例が多い
- V2右肩の角度が強く、V2左肩より回復速度が速い
- V1安値またはV2安値が、過去の安値ライン付近にある
- または、V2右肩の突破が過去高値ライン付近で起きている
- V1右肩高値の近くで一度止まり、V2で再確認してから抜けている
- 価格が高値安値ラインから遠い場所のDouble Vは、見た目の優位性が弱い

このため現行Pineでは、初期仮説を「V2がV1右肩部分を突破したらエントリー」に変更した。

### 2026-06-02 22:16 修正

USDJPY H4で、V1の右肩がV1左肩起点を回復していない部分戻しにもシグナルが出た。

これは狙っている「V字から再点火」ではなく、下落途中の戻り売り内で小さなDouble Vを拾っているだけだった。

そのため以下を追加した。

- V1右肩がV1左肩起点を上抜けない場合は除外
- V1右肩の回復速度がV1左肩の下落速度より弱い場合は除外
- 見送り理由に `V1右肩が左肩未満` / `V1右肩速度不足` を追加

これにより、`急落 -> 部分戻し -> さらに下落中の小さなV2` ではなく、`急落 -> V1で左肩起点を回復 -> V2で再確認 -> V1右肩高値を突破` を狙う。

### 2026-06-02 V2ノイズ除外

候補のエントリーで、V2が小さすぎるノイズまで拾っていた。

原因は、V2下落幅をATRだけで見ていたため、V1が大きい局面では相対的に小さい揺れでもV2として扱われること。

そのため以下を追加した。

- V2下落幅 / V1下落幅 >= 0.25
- V2左肩の最小本数を2本から3本へ変更
- 見送り理由に `V2が小さすぎる` を追加

狙うV2は、ただのノイズではなく、V1右肩高値付近で一度しっかり押してから再突破する形。

### 2026-06-02 ただのV字除外

GBPJPY H4で、Double Vではなく「大きいV字の右肩が伸びた後の小さい押し」に見えるシグナルが出た。

該当例では `V1回復@V2` が 2.61 で、V2開始位置がV1左肩起点から離れすぎていた。

これは `V1 -> V2` ではなく、`大きなV字 -> 上で小さいノイズ` と見る方が自然。

そのため以下を追加した。

- V2開始時のV1回復率上限 = 1.60
- 上限を超えた候補は `V1右肩が伸びすぎ` として除外

狙う形は、V1右肩がV1左肩起点を少し上抜けた近辺でV2を作ること。右肩が伸びすぎた後の小さい押しは対象外。

### 高値安値コンテキスト

2026-06-02のチャート確認で、Double Vは高値・安値付近の方が実戦向きに見えた。

そのためPineに以下を追加した。

- 過去180本の高値/安値を参照
- 直近6本は除外し、現在のV自身でラインが更新されないようにする
- 初期設定では「高値または安値付近」だけを通す
- 安値付近: V1安値またはV2安値が、過去安値 + 2ATR以内
- 高値付近: V2開始高値またはシグナル終値が、過去高値 - 2ATR以内
- フィルタは `なし / 高値または安値付近 / 安値付近のみ / 高値付近のみ` で切替可能

### 売買

- Entry: 条件成立足の次足始値
- SL: V2安値 - 0.25 ATR
- TP: 1.5R
- 最大保有: 180本
- H4前提
- XAUUSDは初期設定で除外
- 12/15〜1/10は新規停止

として表示する。

## 2026-06-02 可視化専用版

目的をバックテスト成績ではなく「見たい形を見つけること」に寄せた可視化Pineを追加した。

ファイル:

- `pine/visual/h4_double_v_short_denial_visual.pine`

この版は、以下を分けて表示する。

- `WATCH`: V1とV2の構造はできたが、まだV1右肩高値を突破していない
- `EXEC`: V2右肩がV1右肩高値を終値で突破した候補
- `SKIP`: 突破っぽい動きはあるが、V1/V2の強さや位置が足りない候補

検出モードは3段階。

- `探索`: 形を多めに拾って目視研究する
- `標準`: まず使う基本モード
- `厳選`: ノイズを強く削る

前回の問題だった「極端に少なくなった」は、厳選条件を固定しすぎたことが原因になりやすい。
そのため、可視化版では最初から `探索 / 標準 / 厳選` を切り替えられるようにした。

この手法の本質は、ただのV字ではない。

狙うのは、

1. V1で急落が否定される
2. V2で戻り売りがもう一度入る
3. V2安値が崩れない
4. V2右肩がV1右肩高値を突破する

という「二段階の売り失敗」。

したがって、チャート確認では `EXEC` だけでなく、`WATCH` が実際に見たい位置へ出ているかを先に見る。
もし `EXEC` が少なすぎる場合は、まず `探索` にして形を拾い、見た目で良い共通点を確認してから `標準` に戻す。
