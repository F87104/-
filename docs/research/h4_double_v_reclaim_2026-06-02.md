# H4 Double V Reclaim 研究メモ 2026-06-02

## 狙い

V字のあとに、もう一度V字を作る形を探す。

最初のVを直接買うのではなく、1回目のVを「売りが失敗した文脈」として使い、2回目のVで右肩が強くなったところを買う。

## 手法名

H4 Double V Reclaim

## ロジック

### V1

- confirmed pivot high から confirmed pivot low への急落
- 下落幅 >= 3.0 ATR
- 左肩速度 >= 0.20 ATR/本
- 左肩本数 2〜36本

### V2

- V1安値の後にできる次の confirmed pivot high -> confirmed pivot low
- V2開始高値が、V1下落幅の61.8%以上まで回復している
- V2安値が、V1の38.2%回復ラインを守っている
- V2下落幅 >= 1.4 ATR
- V2左肩速度 >= 0.15 ATR/本
- V2右肩速度 >= V2左肩速度 x 1.20
- V2右肩終値が、V2左肩起点を0.05ATR上抜け
- 実体比率 >= 45%
- 終値位置 >= 60%

### 高値安値コンテキスト

2026-06-02のチャート確認で、Double Vは高値・安値付近の方が実戦向きに見えた。

そのためPineに以下を追加した。

- 過去180本の高値/安値を参照
- 直近6本は除外し、現在のV自身でラインが更新されないようにする
- 初期設定では「高値または安値付近」だけを通す
- 安値付近: V1安値またはV2安値が、過去安値 + 2ATR以内
- 高値付近: V2開始高値またはシグナル終値が、過去高値 - 2ATR以内
- フィルタは `なし / 高値または安値付近 / 安値付近のみ / 高値付近のみ` で切替可能

### 売買

- Entry: 条件成立足の次足始値
- SL: V2安値 - 0.25 ATR
- TP: 1.5R
- 最大保有: 180本
- H4前提
- XAUUSDは初期設定で除外
- 12/15〜1/10は新規停止

## 使い方

TradingViewでは以下を使う。

- `pine/production/h4_double_v_reclaim_strategy.pine`

チャート上では、

- 薄い赤/緑: V1
- 濃い赤/緑: V2
- `2V`: エントリー候補

として表示する。
