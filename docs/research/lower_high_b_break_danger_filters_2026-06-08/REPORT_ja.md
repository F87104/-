# LH3 B抜け即 危険除外フィルタ検証 v0.1

作成日: 2026-06-08

目的は、B抜け即エントリーを捨てずに、負けやすい形だけを除外できるかを調べること。
前回のB床化検証では、B床化はH4で最大DDを下げる一方、総Rを大きく減らした。そこで今回は、B抜け即の中から危険条件を探す。

## 比較した除外条件

| filter | 意味 |
|---|---|
| BASELINE | B抜け即。除外なし |
| RISK_LE_2_5ATR | 損切り幅が2.5ATR以内 |
| RISK_LE_3ATR | 損切り幅が3.0ATR以内 |
| RANGE_LE_2ATR | エントリー足の高安が2.0ATR以内 |
| BODY_LE_1ATR | エントリー足の実体が1.0ATR以内 |
| BREAK_EXT_LE_0_8ATR | Bから0.8ATR以上伸びた飛び乗りを除外 |
| BREAK_EXT_LE_1_2ATR | Bから1.2ATR以上伸びた飛び乗りを除外 |
| A_ROOM_GE_0_5R | Aが上に残る場合、Aまで0.5R以上 |
| A_ROOM_GE_1R | Aが上に残る場合、Aまで1R以上 |
| NO_D1_RESIST_1ATR | D1過去60日高値が1ATR未満にある場所を除外 |
| D1_CLOSE_GT_EMA20 | D1終値がEMA20より上 |
| CLOSE_LOC_GE_60 | エントリー足の終値位置が上位60%以上 |

| COMBO_STRUCTURE | 損切り3ATR以内 + Bから1.2ATR以内 + Aまで0.5R以上 |
| COMBO_D1 | 損切り3ATR以内 + Bから1.2ATR以内 + A余白 + D1抵抗近接なし |

## 先に結論

- XAUUSD H4では、B抜け即を完全に捨てるより、危険な形だけを除外するほうが自然。
- 現時点の実用候補は `A_ROOM_GE_0_5R`。A水平線が上に残るなら、そこまで最低0.5Rの余白があるものだけをENTRY候補にする。
- `D1_CLOSE_GT_EMA20` はPFが高いが件数が減るため、ENTRY条件ではなく「強い追い風」ラベル向き。
- 巨大足、損切り幅、D1高値近接は、単体ではXAUUSD H4の勝ち負けをきれいに分けなかった。

## 実用候補

- 実用候補 v1 は `A_ROOM_GE_0_5R`。A_ROOM_GE_0_5R: 58件、勝率 67.24%、PF 2.98、総R 26.45R、最大DD 2.50R。 baselineより総Rは少し下がるが、勝率・PF・最大DDのバランスが一番よい。

- 高品質だが狭い条件は `D1_CLOSE_GT_EMA20`。D1_CLOSE_GT_EMA20: 32件、勝率 65.62%、PF 3.52、総R 17.83R、最大DD 1.31R。PFは最も高いが件数が32件まで減るため、本線ではなく強弱ラベル向き。

- `RISK_LE_3ATR` は件数が少なすぎる。RISK_LE_3ATR: 7件、勝率 71.43%、PF 4.87、総R 7.85R、最大DD 1.01R。勝率は高く見えるが7件なので、採用判断には使わない。

## 暫定判断

- B抜け即の主役は、まだXAUUSD H4。
- 次のTradingView表示では、`ENTRY`を出す条件に `A_ROOM_GE_0_5R` を足す案が最も自然。
- `D1_CLOSE_GT_EMA20` はENTRY条件にすると件数が減りすぎるため、強い追い風ラベルとして表示する。
- `CLOSE_LOC_GE_60` は軽い品質ラベルとして候補。終値が足の上側で終わっているかを見る。
- 巨大足・損切り幅・D1高値近接は、単体では今回のXAUUSD H4をうまく分けなかった。
- 件数が30件未満のXAUUSD H4フィルタは、現時点では参考値扱い。
