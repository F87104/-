# LH3 B抜け後サポート化確認 勝率/PF検証 v0.1

作成日: 2026-06-08

目的は、LH3 + 赤LINE上抜け + B水平線上抜けのあと、すぐ入るよりも、Bが床になったことを確認してから入る方が勝率/PFを上げられるかを見ること。

## 比較した入口

| variant | 入口 | 狙い |
|---|---|---|
| ENTRY_A_B_BREAK | B水平線を終値で上抜けた足 | 最速。取り逃しは少ないがダマシを受ける |
| ENTRY_B_B_SUPPORT_REACCEL | B上抜け後、B付近へ浅く戻り、Bを割らずに再上昇 | Bが床になった確認。勝率改善狙い |
| ENTRY_C_A_AFTER_B | B上抜け後、A/H3水平線も終値で上抜け | 強い確認。ただし遅れる可能性 |

## ルール

- 共通: 3回lower high後、赤いLH3下降LINEを終値で上抜け、その後B水平線を上抜ける
- Bサポート化: B上抜け後、lowがB + 0.35ATR以内へ戻る
- B失敗: 終値がB - 0.45ATRより下で失効
- 再上昇: 戻り足高値 + 0.05ATRを終値で上抜け
- SL: H3後からエントリー足までの最安値 - 0.20ATR
- TP: 1R / 1.5R / 2R
- 時間切れ: 48本 / 120本
- R: spread/slippage込み `r_after_cost`

## 重要な気づき

- H4では、Bサポート化確認は「万能の勝率改善」ではなかった。ENTRY_A_B_BREAK RR2.0/120本は勝率 44.72%、PF 1.22、総R 60.14R、最大DD 34.84R。ENTRY_B_B_SUPPORT_REACCEL RR2.0/120本は勝率 46.70%、PF 1.20、総R 20.58R、最大DD 14.88R。
- つまり、B床化は勝率を少し上げ、最大DDをかなり下げるが、件数と総Rを大きく減らす。H4では本線をB抜け即エントリー、B床化を危険回避・ロット調整の補助条件として扱う。
- H1ではB床化の価値が少し変わる。ENTRY_A_B_BREAK RR2.0/120本はPF 1.07、最大DD 59.90R。ENTRY_B_B_SUPPORT_REACCEL RR1.5/120本はPF 1.16、最大DD 13.49R。H1では利益最大化より、荒い振れを減らすフィルタとして研究価値がある。
- 直感では「Bを抜けたあと、一度支えられてから入るほうが強い」と見える。ただし数字では、XAUUSD H4のようにB抜け即のほうが強いケースがある。
- 次は、B床化そのものを入口にするより、B抜け即エントリーから除外すべき危険条件を探す。候補は、巨大陽線で損切りが遠い、A水平線まで距離がない、D1抵抗直下、上抜け後すぐ大陰線でBを割る場面。

今回の読み方:

- 勝率だけでなく、件数、総R、OOS、最大DDを一緒に見る。
- Bサポート化で勝率が上がっても、件数が減りすぎる場合は実運用の候補ではなく補助条件にする。
- B抜け即エントリーが総Rで勝ち、Bサポート化が勝率/DDで勝つなら、リアル運用ではロットを分ける余地がある。
