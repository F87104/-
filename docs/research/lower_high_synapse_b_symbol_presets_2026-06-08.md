# LH3 + B水平線 通貨別プリセット検証Pine

Date: 2026-06-08

## 目的

`LH3赤LINE上抜け + B水平線終値上抜け` を、TradingViewのストラテジーテスターで通貨別に検証する。

目視用ではなく、勝率・PF・ドローダウンを見るための検証用Pine。

## Pine

- [lower_high_synapse_b_symbol_presets_strategy_v0_1.pine](../../pine/research/lower_high_synapse_b_symbol_presets_strategy_v0_1.pine)

## 共通ルール

1. 3つの高値が順に切り下がる
2. 3点を結ぶ赤LINEを終値で上抜ける
3. H3後の安値から反発し、B水平線を作る
4. B水平線を終値で上抜けたらロング検証
5. SLは、H3後からENTRY足までの最安値 - ATR余白
6. TPは通貨別プリセットのRR
7. 最大保有本数を過ぎたら時間切れ決済

## 通貨別プリセット

| プリセット | 推奨足 | RR | 最大保有 | A余白 | 用途 |
|---|---:|---:|---:|---:|---|
| XAUUSD H4 | H4 | 2.0 | 48本 | 0.5R以上 | 本命。過去検証で最も見たい形 |
| GBPJPY H1 | H1 | 2.0 | 120本 | なし | 件数と伸びを重視 |
| USDJPY H1 | H1 | 2.0 | 48本 | なし | H1で短めに確認 |
| EURJPY H4 | H4 | 2.0 | 48本 | なし | H4 B抜けの観察 |
| CHFJPY H4 | H4 | 1.0 | 48本 | なし | 伸びより勝率確認 |
| AUDJPY H4 | H4 | 2.0 | 48本 | なし | H4 B抜けの観察 |
| SILVER H4 | H4 | 2.0 | 48本 | 0.5R以上 | XAUUSDに近いが弱めの観察枠 |
| ALL H4 Balanced | H4 | 2.0 | 120本 | 0.5R以上 | 全体比較用 |

## 補助ラベル

- `D1 EMA`: D1終値がEMA20より上か
- `QUALITY`: B抜け足の終値位置が上側か
- どちらも初期状態ではENTRY条件にしない

## ロット損益

v0.8以降の円換算は `Auto` が初期値。

- JPYペア: `1lot = 価格1.00あたり10,000円`
- 例: クロス円10lotなら、1円動くと `100,000円`
- XAUUSDなどJPY以外: `1lot = 価格1.00あたり100円` を初期仮定
- ブローカーや銘柄仕様が違う場合は `円換算モード = Manual` にして、`価格1.00あたり損益円（Manual）` を直接入れる

つまり、JPYペアで `現在ロット = 10` の場合、右上テーブルの `1.00損益` は `100000円 / Auto` になる。

## 読み方

まずは `Auto` で銘柄別プリセットを使う。

右上の `LH3 B Combo v0.6` 統合テーブルの `preset / TF` が `OK` なら、その時間足で検証する。

`確認` と出る場合は、チャートの時間足がプリセット想定と違う。

テーブルがTradingView上で表示されない環境があったため、v0.2ではチャート上の固定ラベルを主表示にした。その後、2本のインジケーターを重ねると右上テーブルが読みやすいことが分かったため、v0.4では統合テーブルを初期ONに戻した。

v0.4では、`LH3 Synapse B Danger Filter Visual` と `LH3 Synapse B Symbol Presets Strategy` を重ねた時の見やすさを、1本に統合した。

v0.5では、見やすい表示モードで消えていた赤LINEを改善した。履歴の赤LINEを全部戻すのではなく、現在有効なLH3赤LINEだけを太く表示する。

v0.6では、赤LINE履歴を `見やすい表示モード` から独立させた。`赤LINE履歴表示（手動ON/OFF）` をONにすると、過去の赤LINEも薄い赤で表示できる。

v0.7では、精度を上げるために `精度モード` を追加した。初期値は `Precision`。

| モード | 使い方 | ENTRY条件に追加されるもの |
|---|---|---|
| Balanced | 今までの標準検証 | 通貨別プリセットの基本条件 |
| Precision | 実運用寄りに絞る | A余白、終値位置、SL幅3ATR以内、B抜け後の伸び1.2ATR以内 |
| Strict | さらに絞る | Precision条件 + D1 EMA20上、A余白強化、B抜け後の伸び0.8ATR以内 |

今の研究では、まず `XAUUSD H4 / Precision` を本命として見る。

理由は、過去検証でXAUUSD H4は `A余白0.5R以上` に絞ると、勝率とPFが上がり、最大DDが小さくなったため。

- B抜け即 RR2/48: 71件 / 勝率63.38% / PF2.58 / +28.93R / 最大DD5.55R
- A余白0.5R RR2/48: 58件 / 勝率67.24% / PF2.98 / +26.45R / 最大DD2.50R
- D1 EMA20上はPFが高いが件数が減るため、StrictでだけENTRY条件にする

v0.3以降では、画面が読みにくくなる問題を避けるため、`見やすい表示モード（最新中心）` を初期ONにした。

- 過去の大きなENTRYラベルを初期非表示
- 赤LINE履歴は初期非表示。ただし `赤LINE履歴表示（手動ON/OFF）` でいつでも表示可能
- TP/SL/ENTRY水平線履歴を初期非表示
- `QUALITY` などの補助ラベルを初期非表示
- ストラテジー注文は初期OFF

勝率・PFをTradingViewのストラテジーテスターで見る時だけ、`検証注文を出す（勝率/PFを見る時だけON）` をONにする。

固定ラベルも出ない場合は、Pineの問題ではなく次を確認する。

- 貼り付けたコードのタイトルが `v0.6` になっているか
- インジケーター左の目アイコンがONか
- Pineエディタ下部にコンパイルエラーが出ていないか
- チャート上の「ラベル/描画」が非表示になっていないか

## 注意

TradingViewのストラテジーテスターは、データ配信元・スプレッド・同一足内の約定順でPython検証と完全一致しない。

最初は、勝率/PFそのものよりも、ENTRY位置が人間の目で納得できるかを確認する。
