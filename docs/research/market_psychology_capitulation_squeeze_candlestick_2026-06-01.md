# 投げ売り・踏み上げ ローソク足レポート

作成日: 2026-06-01

## 目的

「投げ売り」と「踏み上げ」を、単なる用語ではなく、ローソク足で観察できる群衆心理として整理する。

このレポートは売買サインではなく、Pineで可視化するための研究メモとして使う。

## 用語の整理

| 用語 | 起きていること | 降参する側 | 価格の動き |
|---|---|---|---|
| 投げ売り | 買っていた人が耐えられず、一斉に売る | 買い手 | 下落が加速する |
| 踏み上げ | 売っていた人が耐えられず、一斉に買い戻す | 売り手 | 上昇が加速する |

どちらも共通しているのは、**負けている側の損切りが連鎖し、反対方向へ勢いが出る**こと。

## 投げ売りしやすい相場

買っている人が多いのに、上がらなくなった相場。

ローソク足の例:

```text
連続陽線 -> 上ヒゲ陰線 -> 包み陰線 -> サポート割れ大陰線
```

心理の流れ:

1. 高値圏で陽線が続き、買い手が強気になる
2. しかし高値更新に失敗し、上ヒゲが出る
3. 次の陰線が前の陽線を包み、上昇期待が崩れる
4. 直近安値や水平線を割る
5. 買い手の損切りが一斉に出て、下落が加速する

観察ポイント:

- 高値圏で伸び切っている
- 上ヒゲ、包み陰線、高値更新失敗が出る
- 直近安値、レンジ下限、水平線を終値で割る
- 大陰線の実体が通常より大きい
- 割れた後、戻りが弱ければ売り継続になりやすい

Pineで近似する条件:

```text
高値圏
+ 上ヒゲまたは包み陰線
+ 直近安値割れ
+ TR > ATR x 1.5
```

注意:

投げ売り直後の底買いは、見た目は魅力的でも危険。  
長い下ヒゲだけで買うのではなく、反転継続の確認が必要。

## 踏み上げしやすい相場

売っている人が多いのに、下がらなくなった相場。

ローソク足の例:

```text
急落 -> 下ヒゲ連発 -> 安値圏の小レンジ -> レンジ上抜け大陽線
```

心理の流れ:

1. 大陰線で急落し、売り手が増える
2. 多くの人が「まだ下がる」と考える
3. しかし安値を更新できず、下ヒゲが何本も出る
4. 安値圏で小さな棚を作る
5. 棚の高値を終値で上抜ける
6. 売り手の損切り買い戻しと新規買いが重なり、上昇が加速する

観察ポイント:

- 直前に急落がある
- 急落後に安値を更新できない
- 下ヒゲが複数出る
- 安値圏で狭いレンジ、つまり棚を作る
- 棚高値を終値で上抜ける
- 上抜け後にすぐ棚内へ戻らない

Pineで近似する条件:

```text
N本以内に ATR x 3.5 以上の急落
+ 6本前後の安値圏の棚
+ 棚幅 <= ATR x 2.0
+ 棚高値を終値で上抜け
+ 可能なら出来高増加
```

注意:

これは「底を当てる」手法ではない。  
下がらないことを確認し、売り手が苦しくなった後の上抜けを見る。

## 研究上の結論

投げ売りと踏み上げは、どちらも「降参の連鎖」。

ただし実戦で使うなら、今のところ優先度は次の順番。

| 優先 | 研究対象 | 理由 |
|---:|---|---|
| 1 | 踏み上げ棚ブレイク | 急落後に下がらない確認があり、Pine条件にしやすい |
| 2 | 投げ売り後の戻り失敗 | 下落継続の確認が必要だが、ショート研究として有望 |
| 3 | 投げ売り直後の底買い | 下ヒゲだけでは不十分。出来高と反転継続確認が必要 |

## 次に検証すること

1. TradingViewの実出来高で、踏み上げ棚ブレイクの精度が上がるか見る
2. 上抜け後、1から2本以内に棚内へ戻る失敗形を除外できるか見る
3. 投げ売り側は「高値圏の買い手降参」だけに絞り、ロング版の単純ミラーにしない
4. 受講生データの全敗クラスタに、投げ売り型・踏み上げ型のタグを追加する
5. Pineでは売買サインではなく、まず `CAPITULATION` / `SQUEEZE` の観察ラベルとして表示する

## ひとことで覚える

```text
投げ売り = 買い手が降参して売る
踏み上げ = 売り手が降参して買い戻す
```

チャートで見ると、

```text
投げ売り = 高値圏で上がらなくなり、安値を割る
踏み上げ = 安値圏で下がらなくなり、高値を抜く
```
