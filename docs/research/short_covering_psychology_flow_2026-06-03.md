# Short Covering Psychology Flow 研究メモ 2026-06-03

## 研究の問い

単なるV字やローソク足パターンではなく、売り手の心理が

`売り -> 含み益 -> 安心 -> 反発 -> 不安 -> 損切り -> 買い戻し`

へ変化している可能性が高い場所を、チャート上で可視化できるかを調べる。

## 狙う心理構造

この研究では、以下の3段階を分けて見る。

| 表示 | 意味 |
|---|---|
| SELL DOMINANCE | 売り手が優位。連続下落、安値更新、戻り売り成功により、売りポジションが含み益で安心している可能性 |
| SELL FAILURE / LOW REJECTION | 安値更新失敗、下ヒゲ、強い陽線などで、売り手の安心が崩れ始める場面 |
| SHORT COVERING | 直近戻り高値や売り手の損切り候補ラインを終値で上抜け、買い戻しが起きた可能性 |
| ACCELERATION | ショートカバー後、一定ATR以上の上昇が続き、買い戻しと新規買いが重なった可能性 |

## 初期条件

### SELL DOMINANCE

- 一定本数内の下落幅がATR比で大きい
- 安値更新が複数回ある
- 陰線本数が多い
- EMAへの戻り売りが複数回成功している
- 短期EMAが方向EMAより下にあり、方向EMAも下向き
- 出来高増加はFXではブローカー差があるため、初期値では任意

### SELL FAILURE

- 安値更新後に終値で戻す
- 長い下ヒゲを作る
- 強い陽線で終値位置が高い

### SHORT COVERING

- SELL FAILURE後、直近戻り高値ラインを終値で上抜け
- 実体比率と終値位置が一定以上
- 初期値では陽線を要求

### ACCELERATION

- SHORT COVERING後、指定本数内に一定ATR以上の上昇がある
- 逆に損切りライン内へ戻れば失敗候補として記録

## 重要な考え方

- これはチャートパターン検出ではない
- 売り手が優位だった証拠を先に探す
- その優位が壊れた証拠を次に探す
- 最後に、損切りが連鎖した可能性を観察する

## 失敗パターンとして見るもの

- SELL DOMINANCEが弱い状態での反発
- 安値更新失敗ではなく、単なるレンジ中央の陽線
- SHORT COVERING後にすぐ損切りライン内へ戻る
- 反発が1ATR未満で終わる
- 直近高値付近まで距離がなく、買い戻し余地が小さい

## 2026-06-03 表示調整メモ

TradingView確認で、初期版は `SELL DOMINANCE`、`SELL FAILURE`、`SHORT COVERING`、`ACCELERATION`、事後分析ラベルをすべて表示していたため、チャートが読みづらくなった。

今回の修正では、初期表示を **実戦レビュー** に寄せ、普段は `SHORT COVERING` と `ACCELERATION` だけを主役にする。

- `SELL DOMINANCE` / `SELL FAILURE` の詳細ラベルは初期OFF
- 背景表示は初期OFF
- 事後分析ラベルは初期「なし」
- `詳細研究` モードに切り替えると、4段階すべてを確認できる
- 売り優勢と踏み上げ条件を少し厳格化
- 同一フローの再表示間隔を80本に延長し、観察中の新規フロー開始を抑制

理由: この研究対象は「売り手の損切り買い戻しが起きた可能性」であり、実戦画面では候補段階の赤ラベルを大量に見るより、損切り連鎖が始まった可能性のある `SHORT COVERING` / `ACCELERATION` に集中した方がよい。

### 再調整

上記の厳格化後、実戦レビューで入口候補がほぼ出なくなったため、検出条件は標準感度へ戻した。

- 下落幅、安値更新回数、陰線本数、戻り売り成功回数は初期研究値に戻す
- 踏み上げ足の実体比率と終値位置も初期研究値へ戻す
- 表示は静かなまま維持する

結論: **候補を減らす役割は表示モードに任せ、検出ロジックはまず十分な候補が出る標準感度で観察する。**
