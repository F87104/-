# 受講生エントリー集中パターン研究

## 研究の問い

複数の受講生が、同じようなチャート形状でエントリーしているなら、そこには人間が反応しやすい理由がある。
その場所を集めることで、失敗パターンだけでなく、成功パターンの入口や「待つべき場所」のヒントを探す。

## 考え方

1人のトレードだけを見ると、その人の癖に見える。
しかし、複数人が同じような場所で入っているなら、それは個人の癖ではなく、チャートが人間にそう見せている可能性がある。

この研究では、各トレードを次の順番で見る。

1. どのチャート形状で入ったか
2. 何人が同じ形で入っているか
3. その形は勝ちやすいのか、負けやすいのか
4. 勝った例と負けた例で、入る前に何が違うのか
5. Pineで `STOP`、`WAIT`、`CHECK` にできるか

## 今回の気づき

- 受講生が一番多く反応しているのは、節目抜け・ブレイクである。
- 「同じ形で多くの人が入る場所」は、勝ちやすい場所とは限らない。むしろ群衆が反応しやすい場所として `STOP` 候補になる。
- トレンド継続期待は損失率が極端に悪いわけではないため、単純に禁止するより「伸び切りか、押し戻り後か」を分ける必要がある。
- V字・急反転期待は人数が多く、成功例にも失敗例にも出る。差は、V字そのものではなく、V字後の停滞・再加速・否定位置にある。
- ローソク足単体判断は件数は少ないが損失率が高く、教材化しやすい。
- 取り返し反応は件数は少ないが、心理としては強い。チャート形状よりも、直前の損切りや後悔とセットで見る。

## 研究の次の焦点

次は、件数が多い順ではなく、ヒントが強い順に見る。

| 優先 | 見るパターン | 理由 |
|---:|---|---|
| 1 | 節目抜け・ブレイク飛び乗り | 人数が多く、Pineの `STOP` にしやすい |
| 2 | V字・急反転期待 | 成功例と失敗例の差を見つけやすい |
| 3 | レンジ中央・急変反応 | 見送りルールに変換しやすい |
| 4 | ローソク足単体判断 | 損失率が高く、教材化しやすい |
| 5 | トレンド継続期待 | 禁止ではなく、良い入口と悪い入口を分ける |

## P01 画像照合 v0.1

P01「節目抜け・ブレイク飛び乗り」について、匿名化済みデータと抽出済みチャート画像を照合した。
元画像と個別引用は公開せず、集計だけを残す。

| 項目 | 件数 |
|---|---:|
| 画像照合できたP01候補 | 162 |
| 匿名ID数 | 28 |
| 損失/撤退 | 94 |
| 利益/利確 | 30 |
| 不明 | 38 |
| 確認用20枚シート | 損失10 / 利益10 |

画像20件を並べて見えたこと:

- 勝ち負けの両方に「抵抗線抜け」「高値停滞」「安値停滞」「V字」「2回目ブレイク」が出る。
- つまり、単語や形だけでは成功/失敗を分けられない。
- 失敗側は、抜けた直後、停滞を見た直後、または「ロスカットが溜まっているはず」という期待で意味づけが早い。
- 成功側は、同じブレイクでも、戻り、再停滞、再ブレイク、ストップ位置の確認が入っている例が多い。
- 「複数人が入る場所」は、そのまま成功地点ではなく、まず人間が反応する `STOP` 地点として扱う方が安全。
- 成功候補は、`STOP` のあとに待った結果として出る `CHECK` 地点で探す。

P01の暫定ルール:

| 表示 | 条件の考え方 |
|---|---|
| `STOP` | 節目を抜けた直後、または停滞を見てすぐ期待で入る場所 |
| `WAIT` | 抜け後に戻り・再停滞を確認している途中 |
| `CHECK` | 抜け後に一度待ち、再加速または再ブレイクが出た場所 |

P01で一番重要な仮説:

> ブレイクが勝たせるのではなく、ブレイク後に待てたかどうかが分岐になる。

## P01 STOP/CHECK変換 v0.1

20枚マーキングをもとに、Pineのシンプル版へ次のように変換した。

| 表示 | Pine条件の方向 | 理由 |
|---|---|---|
| `STOP` | 節目を強い足で抜けた直後 | 受講生が最も反応しやすく、損失側にも多い |
| `WAIT` | 抜け後に節目付近へ押し戻った状態 | ここではまだ入らず、再確認だけを見る |
| `CHECK` | 押し戻り後に再び進み、節目外に残る | 成功側に多い「待った後」の候補 |

シンプル版Pineの変更:

- `Crowd Psychology Simple v0.2` に更新
- `節目抜け直後をSTOP` を追加し、抜けた瞬間を広めに赤表示する
- `CHECKにEMA方向一致を使う` を追加し、必要な時だけ方向フィルタをONにできる
- `CHECK` は、抜け後の押し戻り確認を経てから再加速した場所に限定する

## TradingView確認 v0.2からの改善点

GBPJPY H1で確認したところ、v0.2は考え方は合っていたが、リアルタイムで使うにはまだ表示が多かった。
特に `CHECK` が簡単に出すぎて、候補が多すぎる状態になっていた。

改善点:

- `CHECK` は「抜け後に最低4本待ったあと」の押し戻り確認が必要
- `CHECK` は節目を少し上回る/下回る再加速を必須にする
- `CHECK` は初期状態でEMA方向一致を必須にする
- `STOP/WAIT/CHECK` の文字を `S/W/C` に短縮する
- 同じ表示の間隔を24本から48本へ広げる
- 節目lookbackを96本から144本へ広げ、細かい節目を減らす
- レンジlookbackを72本から96本へ広げる

v0.3の目的:

> 候補を増やすことではなく、迷う回数を減らすこと。

v0.3での読み方:

| 表示 | 意味 | 行動 |
|---|---|---|
| `S` | STOP。多くの人が反応しやすい場所 | 入らない |
| `W` | WAIT。押し戻り確認中 | 待つ |
| `C` | CHECK。待った後の再加速候補 | 損切り位置だけ確認 |

## TradingView確認 v0.3: GBPJPY H1

v0.3をGBPJPY H1に貼った結果、v0.2より表示量はかなり整理された。
`S/W/C` の3文字にしたことで、チャートを読みながら心理の位置だけを確認しやすくなった。

私の見立て:

- `S` はかなり良い。高値抜け、安値抜け、勢いの途中、天井付近など、人が反応したくなる場所に出ている。
- `S` は反転サインではない。強いトレンドでは `S` のあとも伸びることがあるため、「逆張り」ではなく「即エントリー禁止」として読む。
- `W` は重要。黄色が出ている場所は、値動きが一度冷める場所で、受講生データでいう「待てたかどうか」を見るのに向いている。
- `C` はv0.2より良くなった。特に安値圏からの切り返し後、または上昇トレンド中の押し戻り後に出る `C` は研究候補になる。
- ただし `C` もまだ売買サインではない。レンジの中や転換直後では、上位足方向と損切り位置がないと危ない。
- この表示は「勝てる場所を当てる」より、「多くの人が早く入りそうな場所」と「待った後に確認する場所」を分ける用途に合っている。

このデータから見えること:

> 受講生が入りやすい場所は、チャート上でもかなり再現できる。
> ただし、成功/失敗の差は形そのものではなく、Sの直後に反応したか、Wを待ってCまで待てたかに出る。

次の改善候補:

- `C` は1つのブレイクシーケンスにつき1回だけ出す
- `C` に上位足方向フィルタを追加する
- レンジ中の `C` は弱い候補として別色または非表示にする
- `S` が連続する場所を「群衆密集ゾーン」として背景表示する
- まずはv0.3のまま、20例だけ目視記録して過剰調整を避ける

運用上の読み方:

- 赤 `STOP` は「多くの人が入りたくなる場所」
- 黄色 `WAIT` は「待てている途中」
- 緑 `CHECK` は「候補として確認してよい場所」
- 緑でも損切り位置が見えない場合は見送り

## 正確なチャート照合に必要な列

本当に「同じチャートの同じ場所」で複数人が入っているかを見るには、次の列を追加する。

| 列 | 内容 |
|---|---|
| entry_datetime | エントリー時刻 |
| pair | 通貨ペア |
| timeframe | 見ていた時間足 |
| direction | buy / sell |
| entry_price | エントリー価格 |
| pattern_id | P01、P02など |
| pre_entry_state | 抜け直後、戻り待ち、レンジ中央、V字後など |
| image_id | 該当チャート画像ID |

この列がそろうと、同じ通貨ペア・同じ時間帯・同じ形で入った受講生をクラスタ化できる。

## Pineへの変換

シンプル版では次の3つにする。

| 表示 | データから見たい意味 |
|---|---|
| `STOP` | 複数人が反応しやすいが、負けやすい入口 |
| `WAIT` | その形が出たあと、まだ確認中の場所 |
| `CHECK` | 待った後に、成功例と近い条件が出た場所 |
