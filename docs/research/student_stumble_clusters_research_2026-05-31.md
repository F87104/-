# 受講生「つまずきクラスタ」分析 v0.2（実日時×実価格ベース）

## 研究の問い

複数の受講生が、**同じ日時・同じ価格帯**で入って失敗している場所はどこか。
そこを TradingView 上で重ねると、教材化と v2.x フィルタの両方に使えるか。

## 方法

- データ: [student_entries_extracted.csv](student_entries_extracted.csv)（チャート画像から抽出した **137件** の実エントリー、匿名IDのみ）
  - 抽出項目: 通貨 / 売買 / 時間軸 / エントリー日時(JST) / エントリー価格 / 決済価格 / pips / 勝敗
  - 信頼度: high 113 / medium 18 / low 6（手入力誤記は note でフラグ）
- クラスタ定義: **同一通貨 × 48時間以内 × 価格近接**（GBPJPY ±0.8円 / 円ペア ±0.6円 / XAUUSD ±25ドル）で、
  **2名以上の別受講生**が入っている塊。
- 出力: [student_stumble_clusters_v0_2.csv](student_stumble_clusters_v0_2.csv)（全29クラスタ）

## 全体像

- 抽出137件のうち **損失84 / 利益53**（失敗が約61%）。
- 通貨別: GBPJPY 60 / XAUUSD 42 / USDJPY 16 / EURJPY 9 / その他10。
- クラスタ29個中、**15個が「全員が負けた」全敗クラスタ**＝真のつまずきポイント。

## 解釈（つまずきの共通構造）

1. **GBPJPYの「節目高値追い買い」**（199 / 195 / 194 円台）が最頻・最大の失敗。上昇トレンドの伸び切った所で
   キリの良い節目手前に飛び乗り、直後の反落で損切り。→ **5人全敗の199円台**が象徴。
2. **GBPJPYの「安値売り（落ちるナイフ）」**（2025年2月の188 / 187円台）。急落を見て売り増し、踏み上げで損失。
3. **XAUUSDの「天井買い」**（2719 / 2777 / 2948）。強い上昇の最終局面で買い、短期反落で損切り。
4. 多くが **主要軸1時間足** で、節目・直近高安への「待てずに飛び乗り」型。

## v2.x への示唆（フィルタ候補）

- **節目（00/50銭、ラウンド価格）の手前 N pips での順張り飛び乗りを抑制**するフィルタ。
- **直近大陽線/大陰線の後の1〜2本目での同方向エントリーを除外**（伸び切り検知）。
- XAUUSD は**強い上昇の最終加速での新規買いを抑制**（ATR拡大＋上ヒゲ）。
- これらは「失敗の逆」ではなく「**みんながやる飛び乗りを1テンポ待つ**」フィルタとして v2.x に追加検証する。

| ルール | 件数 | 意味 | 例 |
|---|---:|---|---|
| pullback | 10 | 飛び乗りより1段押し/戻りを待つ | GBPJPY 199追い → **196押し** |
| bounce | 4 | 底/天井で逆張りせず戻りを待つ | GBPJPY 188売り → **190戻り売り** |
| confirmation | 1 | 再加速・定着を確認してから | GBPJPY 192追随 → **193確認後** |
