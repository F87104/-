## 想定される TV 5件との差分原因（優先度順）

1. **TVチャートのライブOHLC ≠ エクスポートCSV**（特に2021/2026のピボット確定・棚安値）
2. **ATR丸め差** → 2025-03-21 の risk_atr が 2.2 を僅かに超え skip 10（リスク幅NG）
3. **ストラテジー状態** — `flatNow`（pending / 決済バー）で V候補開始が数本遅れ → `contextAge < 6` で棚監視未開始
4. Pine設定の手動変更（`maxRiskAtr` / `pivotWidth` 等）— デフォルトなら上記1–3

**否定済み:** ポジション重複、usedPairs のカスケード（TVの方が used が少なく、むしろシグナル増要因）
