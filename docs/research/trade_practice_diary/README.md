## 新規追加の手順

1. `images/` にスクリーンショットを保存（命名: `YYYY-MM-DD_<symbol>_NN_<説明>.png`）
2. 本フォルダに Markdown を追加（写真を `![](images/...)` で埋め込む）
3. [trade_practice_diary.csv](../trade_practice_diary.csv) に1行追加
