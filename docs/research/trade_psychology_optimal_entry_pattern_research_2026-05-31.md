# トレード心理研究: 最適エントリーパターン抽出

## 研究の仮説

資料が豊富にあるため、失敗パターンだけでなく、エントリーに適したパターンも読める可能性が高い。
ただし「最適」は1つの形ではなく、環境認識、節目、待ち方、損切り位置、心理状態がそろった場所として定義する。

## 失敗研究から成功研究へつなぐ考え方

失敗している人の逆をそのまま売買方向の反対にするのではなく、次のように変換する。

| 失敗の入り方 | 成功候補への変換 |
|---|---|
| 抜けた瞬間に飛び乗る | 抜けたあと、押し戻り・再停滞・再加速を待つ |
| レンジ中央の急変に反応する | レンジ端またはレンジ外定着を待つ |
| ローソク足1本だけで判断する | 節目、上位足、次足確認など追加根拠を待つ |
| 損切り位置が曖昧なまま入る | 入る前に否定ラインを決める |
| 感情で取り返そうとする | 入らない理由が消えるまで待つ |

## 抽出する構造化データ

今後は各トレードを、失敗・成功の両方で同じ列にそろえる。

| 項目 | 内容 |
|---|---|
| 匿名ID | 個人を特定しない研究用ID |
| ケースID | チャートまたは報告単位のID |
| 通貨ペア | 取引対象 |
| 時間足 | H1、H4など |
| 結果 | 勝ち、負け、建値、途中撤退 |
| 環境認識 | 上昇、下降、レンジ、転換候補 |
| 節目タイプ | 高安値、レンジ端、水平線、MA、上位足節目 |
| エントリー型 | 抜け再確認、押し戻り、レンジ端反発、レンジ外定着、転換確認 |
| 入る直前の確認 | 次足確認、戻り確認、再加速、否定ライン明確化 |
| 損切り根拠 | 直近高安値、節目割れ、シナリオ否定 |
| 感情 | 焦り、冷静、待てた、不安、取り返したい |
| Saiフィードバック | 改善に使える指摘だけを要約 |
| 成功パターン | 再現できる短いルール |
| 失敗パターン | 同じ形で負けた場合の注意点 |
| Pine候補 | 条件化できるか、目視専用か |
| 信頼度 | 高、中、低 |

## 最初に探すエントリーパターン候補

| 候補 | 見るポイント | Pine化しやすさ |
|---|---|---|
| E01 節目抜け後の再確認 | 抜けたあとに押し戻り、再び進む | 高 |
| E02 レンジ外定着 | レンジ中央ではなく、外へ出て戻り確認がある | 高 |
| E03 レンジ端反発 | レンジ端で止まり、中央では入らない | 中 |
| E04 押し戻り継続 | トレンド中に伸び切りではなく押し戻りから入る | 中 |
| E05 転換確認 | ヒゲや急反発だけでなく、次足確認と節目がある | 中 |

## 検証方法

1. 成功トレードだけを先に集めず、失敗トレードと同じ条件で並べる
2. エントリー後の結果を見てから理由を作らないよう、入る直前に見えていた情報だけを書く
3. 同じチャート形状で、勝った例と負けた例をペアにする
4. 勝った例に共通していて、負けた例に欠けている条件を探す
5. 条件が言語化できたものだけPine候補にする

## 次にやること

1. 既存の構造化データに `エントリー型` と `入る直前の確認` を追加する
2. 成功トレードを優先して10から20件抽出する
3. 失敗トレードと成功トレードを同じパターン別にペア比較する
4. E01とE02をPineの緑サイン候補として強化する
5. E03からE05は、まず目視教材にしてからPine化するか判断する
