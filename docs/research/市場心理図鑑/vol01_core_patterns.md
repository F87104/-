## 01｜売り方降伏

### 心理

«ここまで下がったら必ず反発する»  
«まだ戻るはず、損切りは我慢»  
«あ、戻ってる…もう遅い»

### 感情カテゴリ

**降伏**（主）／恐怖／後悔

### 感情の流れ

```
期待（下落継続）
    ↓
逆行（急反発）
    ↓
執着（損切り先延ばし）
    ↓
恐怖（踏み上げ加速）
    ↓
降伏（ショートカバー一斉）
```

### ローソク足特徴

- 6〜10本以内に ATR×3 以上の急落
- 最終足に長い下ヒゲ、活動量急増
- 翌数本で左肩起点を終値で回収
- 右肩速度 ≥ 左肩速度 × 1.0

### 実際に起きていること

ショートの損切りが連鎖し、新規ロングは「反転確認待ち」で遅れ、**既存ショートの買い戻しだけ**が価格を押し上げる。ファンダメンタルはまだ弱いのに、需給だけが先に反転する。

### 検証仮説

```pine
// Event: 売り方降伏
atr = ta.atr(14)
drop = ta.lowest(low, 8) == low and (ta.highest(high, 8) - low) >= atr * 3.0
reclaim = close > ta.highest(high, 8)[1]
right_vel = (close - low) / 4
left_vel  = (ta.highest(high, 8)[1] - low[4]) / 4
seller_surrender = drop and reclaim and right_vel >= left_vel
```

```python
# Python equivalent
drop = (low == low.rolling(8).min()) & ((high.rolling(8).max() - low) >= atr(14) * 3.0)
reclaim = close > high.rolling(8).max().shift(1)
```

### 期待される結果

- 24〜72本以内に MFE > MAE（上方向）
- 直接V買いより、**棚形成後の再ブレイク**の方が継続しやすい
- D1売り文脈と合成すると精度が上がる

### 教訓

**反転の第一声は「売り方の降伏」であり、まだ買い方の確信ではない** — 入るなら踏み上げの「確認後」。

## 02｜期待先行

### 心理

«抜けた、今入らないと遅れる»  
«やっぱりダマ…いや、まだ戻る»  
«閉じ込められた»

### 感情カテゴリ

**期待**（主）／後悔／恐怖

### 感情の流れ

```
期待（ブレイク成功）
    ↓
先回り（飛び乗り）
    ↓
否定（終値で節目内へ戻る）
    ↓
後悔（損切り or 塩漬け）
```

### ローソク足特徴

- Donchian 20/55 高値（または安値）を終値更新
- 1〜4本以内にブレイク水準を**終値**で否定
- 否定足の TR ≥ ATR×1.3
- 活動量が平均より高い

### 実際に起きていること

**最後に飛び乗った層**（遅れて来た参加者）が流動性を提供し、先に入っていた層が利確。ブレイクを「成功」と解釈した人だけが残り、需給が一方向に偏る。

### 検証仮説

```pine
break_level = ta.highest(high, 20)[1]
broke = close > break_level
denied_1 = close[1] <= break_level
denied_2 = close[2] <= break_level
expectation_ahead = broke[1] and (denied_1 or denied_2) and ta.tr > ta.atr(14) * 1.3
```

```python
break_level = high.rolling(20).max().shift(1)
broke = close.shift(1) > break_level.shift(1)
denied = (close <= break_level) | (close.shift(1) <= break_level.shift(1))
trap = broke & denied & (true_range > atr(14) * 1.3)
```

### 期待される結果

- 否定後 12〜48本、逆方向への MAE > MFE
- H4単独逆張りは弱い。**D1文脈**と合成が必要

### 教訓

**「抜けた」は事実ではなく解釈** — 終値が節目内に戻った瞬間、期待先行層の心理は一気に後悔へ反転する。

## 03｜市場の迷い

### 心理

«上も下も、どちらも説明がつく»  
«動かないうちは様子見»  
«どっちに振れるか分からない»

### 感情カテゴリ

**迷い**（主）／無関心

### 感情の流れ

```
迷い（方向不明）
    ↓
無関心（参加者離脱）
    ↓
蓄圧（ボラ収縮）
    ↓
期待（どちらかに振れる）
```

### ローソク足特徴

- 直近6本レンジ ≤ ATR×2.0
- BB Width < SMA(BB Width, 20)×0.8
- ATR < SMA(ATR, 20)×0.85
- 小実体のローソク足が連続

### 実際に起きていること

方向に確信を持つ参加者が減り、**新規エントリーが止まる**。残っているのは「まだ決断していない」ポジションとアルゴのレンジ売買。需給の均衡点で価格が停滞する。

### 検証仮説

```pine
bb_basis = ta.sma(close, 20)
bb_width = (ta.bbupper(close, 20, 2) - ta.bblower(close, 20, 2)) / bb_basis
compression = bb_width < ta.sma(bb_width, 20) * 0.8
range_n = ta.highest(high, 6) - ta.lowest(low, 6)
shelf = range_n <= ta.atr(14) * 2.0
market_indecision = compression and shelf
```

### 期待される結果

- 単独では方向ランダムに近い
- ブレイク後に **ボラティリティ拡大**（スクイーズ）
- 方向フィルタ（上位TFトレンド）と合成で意味が出る

### 教訓

**迷いは「何も起きていない」状態ではなく、参加者が決断を先延ばししている状態** — 形より「誰も動かない理由」を見る。

## 04｜損失回収モード

### 心理

«あと少し戻れば元が取れる»  
«ここで切ったら本当の損になる»  
«追い足しで平均を下げよう»

### 感情カテゴリ

**回収欲求**（主）／執着／希望

### 感情の流れ

```
後悔（含み損）
    ↓
回収欲求（ナンピン）
    ↓
執着（損切り拒否）
    ↓
恐怖 or 降伏（限界突破）
```

### ローソク足特徴

- 既存トレンド方向への押し目が浅くならない
- 同方向への反発が弱い（高値/安値更新失敗）
- 活動量は増えるが、方向に進まない
- 戻り余地があるゾーンで停滞

### 実際に起きていること

**負けている側が需給を支えている**。ロングの損失回収モードなら「戻り売り」が増え、ショートの損失回収モードなら「押し目買い」が増える。トレンドは一見続くが、**新規の確信買い/売りではなく、既存ポジションの維持**が価格を支える。

### 検証仮説

```python
# 下落トレンド中の損失回収モード（ロング側）
downtrend = (close < ema50) & (ema50.diff(20) < 0)
failed_reclaim = (close < high.rolling(10).max()) & (true_range.rolling(5).mean() > atr(14))
recovery_mode = downtrend & failed_reclaim & (close > low.rolling(20).min())
```

```pine
downtrend = close < ta.ema(close, 50) and ta.ema(close, 50) < ta.ema(close, 50)[20]
failed_reclaim = close < ta.highest(high, 10) and ta.tr > ta.atr(14)
recovery_mode = downtrend and failed_reclaim
```

### 期待される結果

- 一時的な反発（安堵の買い戻し）に見える
- 本物の反転にはならず、**トレンド再開 or 最終投げ**へ移行しやすい

### 教訓

**反発の原因が「新規の確信」ではなく「損失回収」なら、その反発は燃料が尽きる** — 誰の買い/売りかを問う。

## 05｜現実否認

### 心理

«これは一時的な調整だ»  
«ファンダメンタルはまだ強い»  
«いつか必ず戻る»

### 感情カテゴリ

**執着**（主）／希望 → **降伏**

### 感情の流れ

```
利益防衛（含み益確保）
    ↓
希望（調整と解釈）
    ↓
執着（ポジション維持）
    ↓
恐怖（節目割れ）
    ↓
降伏（投げ）
```

### ローソク足特徴

- 長期上昇後、初めての深い押し
- 重要な pivot を**ヒゲだけ**で守る（終値は割れない）
- 3〜5回目のテストで実体が弱くなる
- 最終的に終値で節目割れ

### 実際に起きていること

**ロング保有者が「まだ大丈夫」と自分に言い聞かせている**。需給上は買いが減り、売りはまだ控えめ。否認が続く間は緩やかに下落し、否認が崩れた瞬間に**一気にロング清算**が走る。

### 検証仮説

```pine
uptrend = close > ta.ema(close, 50) and ta.ema(close, 50) > ta.ema(close, 50)[20]
pivot = ta.pivotlow(low, 5, 5)
wick_hold = low <= pivot and close > pivot
denial_break = close < pivot and uptrend[10]
reality_denial = denial_break and ta.atr(14) > ta.sma(ta.atr(14), 20) * 1.2
```

### 期待される結果

- 否認崩れ後 24〜48本、下方向 MFE > MAE
- 単純ミラー（Long Liquidation）は弱かった — **「否認の回数」と「終値割れ」**が鍵

### 教訓

**ヒゲで守られた節目は「強さ」ではなく「まだ降りられていない」** — 終値が割れた瞬間、心理は希望から恐怖へ一気に切り替わる。

## 06｜利益取り逃し恐怖

### 心理

«まだ伸びるかも…いや、確実に取ろう»  
«戻る前に逃げなきゃ»  
«あ、まだ上がってる…乗り遅れた»

### 感情カテゴリ

**利益防衛**（主）／恐怖／期待

### 感情の流れ

```
期待（トレンド継続）
    ↓
利益防衛（早期利確）
    ↓
恐怖（押し目で踏み外し）
    ↓
期待（再び高値更新）
    ↓
利益取り逃し恐怖（飛び乗り）
```

### ローソク足特徴

- 高値更新連発、押し目が浅い
- ADX > 25、ATR 拡大中
- 陽線の実体は小さく、上ヒゲが増える
- 5本以上連続で高値更新

### 実際に起きていること

**早く利確した層が追いかけて再エントリー**し、需給が一方向に偏る。まだトレンドは生きているが、参加者の平均建値が高くなり、**「最後の買い」層**が厚くなる。

### 検証仮説

```pine
hh1 = high > high[1]
hh2 = high[1] > high[2]
hh3 = high[2] > high[3]
hh4 = high[3] > high[4]
hh5 = high[4] > high[5]
fomo_zone = hh1 and hh2 and hh3 and hh4 and hh5
    and ta.adx(14) > 25
    and ta.atr(14) > ta.sma(ta.atr(14), 20) * 1.2
```

### 期待される結果

- 短期はトレンド継続
- 中期的には **正解待ち疲弊**（大多数の方向への逆走）リスク増
- 利確設計が最重要

### 教訓

**トレンドの後半は「儲かった人の再参加」で支えられる** — 伸びているから安全ではなく、参加者の不安が増えているサイン。

## 07｜正解待ち疲弊

### 心理

«自分の分析は合っている、あとは時間の問題»  
«もう限界…認めたくないけど降りる»  
«みんな同じ方向、自分だけ違うわけない»

### 感情カテゴリ

**執着** → **降伏**（主）／後悔

### 感情の流れ

```
期待（方向確信）
    ↓
執着（逆行に耐える）
    ↓
疲弊（時間と資金の消耗）
    ↓
降伏（一方向への投げ）
```

### ローソク足特徴

- 一方向に 15〜30 本以上の偏り
- 最後に ATR×2 以上の逆方向急走
- Donchian 55 更新後、5本以内に反対側更新
- 過熱方向からの急反転

### 実際に起きていること

**片側に偏った参加者が限界を迎える**。ショートカバーとロング清算が同時多発し、価格はファンダメンタルより「ポジションの物理」で動く。

### 検証仮説

```python
extended = (close - close.shift(20)) / atr(14) > 4.0
reversal = close < low.rolling(5).min().shift(1)
pain_event = extended & reversal & (true_range > atr(14) * 2.0)
```

```pine
extended = (close - close[20]) / ta.atr(14) > 4.0
reversal = close < ta.lowest(low, 5)[1]
exhaustion = extended[1] and reversal and ta.tr > ta.atr(14) * 2.0
```

### 期待される結果

- 48〜72本、逆方向 MFE > 方向側 MFE
- エントリーは「疲弊確認後」の再ブレイク

### 教訓

**「正しい」人が多いほど、市場はその正解を証明する前に逆走する** — 人数ではなく、限界資金が動いた瞬間を見る。

## 08｜静寂の蓄圧

### 心理

«動かない、つまらない»  
«もう見るのをやめよう»  
«あ、動いた…何が起きた？」

### 感情カテゴリ

**無関心** → **期待**（主）／恐怖

### 感情の流れ

```
無関心（ボラ低下）
    ↓
離脱（参加者減）
    ↓
蓄圧（エネルギー蓄積）
    ↓
期待 or 恐怖（一方向解放）
```

### ローソク足特徴

- ATR 20本平均の 0.75 倍以下が 10 本以上継続
- BB Width が 20 本平均の 0.75 倍以下
- その後 TR ≥ ATR×2.0 の breakout 足
- ブレイク方向に終値が明確

### 実際に起きていること

**流動性提供者（マーケットメーカー、アルゴ）だけが残る**。方向性のある参加者が消え、小さな注文 imbalance でも大きく動く。需給の「空っぽさ」が急拡大の燃料。

### 検証仮説

```pine
atr_calm = ta.atr(14) < ta.sma(ta.atr(14), 20) * 0.75
calm_bars = ta.barssince(not atr_calm) >= 10
expansion = ta.tr > ta.atr(14) * 2.0
break_up = close > ta.highest(high, 20)[1]
break_dn = close < ta.lowest(low, 20)[1]
silent_squeeze = calm_bars and expansion and (break_up or break_dn)
```

### 期待される結果

- ブレイク方向へ 24本 MFE > MAE
- 単独は **期待先行** 混在 — 終値確認必須

### 教訓

**退屈は相場の終わりではなく、参加者の離脱** — 誰も見ていないときに最も大きく動く。

## 09｜最後の信念者

### 心理

«ここが底だ、歴史的な買い場»  
«まだ早い、もっと下がる»  
«信じていた人だけが残った…もう無理»

### 感情カテゴリ

**希望** → **降伏**（主）／恐怖

### 感情の流れ

```
希望（底打ち期待）
    ↓
先回り（一部の買い）
    ↓
恐怖（さらなる下落）
    ↓
降伏（最後の投げ）
```

### ローソク足特徴

- 長期下落（120本以上で安値更新）
- 2〜3回の底値テスト
- 最終テストで長い下ヒゲ + 活動量最大
- 次足で前足高値を終値更新

### 実際に起きていること

**「底だ」と信じた層が最後まで残り、そこで投げる**。ファンダメンタル的な底ではなく、**心理底**（もう誰も売りたくない/買えない瞬間）。

### 検証仮説

```python
long_downtrend = close < close.shift(120)
double_test = abs(low - low.shift(10)) < atr(14) * 0.5
capitulation_bar = ((high - low) > atr(14) * 2.5) & ((close - low) / (high - low + 1e-9) > 0.6)
reversal = close > high.shift(1)
last_believer = long_downtrend & double_test & capitulation_bar & reversal
```

### 期待される結果

- 12〜24本の反発
- **48本以降の継続**には D1 文脈 + 棚ブレイクが必要
- 単独 V 買いは弱い（検証済みアンチパターン AP3）

### 教訓

**底は「安いから」ではなく「もう売る人がいなくなったから」** — 二番底の形より、最後の投げの有無を見る。

## 10｜休眠節目の覚醒

### 心理

«何年も触れなかったラインを超えた»  
«ここを超えたら大局が変わる»  
«様子見していた資金が動き出す»

### 感情カテゴリ

**期待**（主）／恐怖

### 感情の流れ

```
無関心（長期停滞）
    ↓
期待（節目接近）
    ↓
先回り（一部の飛び乗り）
    ↓
確認（押し目維持） or 期待先行（否定）
```

### ローソク足特徴

- 120 / 360 / 1250 本の Donchian 高値（安値）を終値更新
- 更新前に 20 本以上、その節目に触れていない
- 更新後 6 本以内に棚形成（レンジ ≤ ATR×2.5）
- 棚高値の再ブレイク

### 実際に起きていること

**長期間「入る理由がなかった」資金**が一斉に方向を決める。需給の壁が消え、一度超えると反対側に抵抗が薄い。ただし初回更新は期待先行も多い。

### 検証仮説

```pine
dormant_high = ta.highest(high, 360)[1]
untouched = ta.barssince(high >= dormant_high * 0.998) >= 20
awakening = close > dormant_high and untouched
shelf_after = (ta.highest(high, 6) - ta.lowest(low, 6)) <= ta.atr(14) * 2.5
entry = awakening[6] and close > ta.highest(high, 6)[1]
```

### 期待される結果

- 中長期トレンド開始候補
- V 手法のフィルタではなく**独立した大局ブレイク**として検証が必要
- 初押し維持 + 再ブレイクが Entry trigger

### 教訓

**長く触れなかった節目は「ライン」ではなく「忘却された約束」** — 超えた瞬間、市場の記憶が一斉に蘇る。

## 11｜続落期待の崩壊

### 心理

«この勢いならまだ下がる»  
«え、戻ってる…空売り増やそう»  
«もう下がらない…ショート損切り»

### 感情カテゴリ

**期待** → **後悔** → **降伏**（主）

### 感情の流れ

```
期待（下落継続）
    ↓
追加（空売り増）
    ↓
否定（高値更新）
    ↓
降伏（踏み上げ）
```

### ローソク足特徴

- 急落後 4〜8 本で安値更新停止
- 左肩起点（急落開始点）を終値で回収
- 活動量は高いまま
- 押し目でも安値を更新できない

### 実際に起きていること

**「まだ下がるはず」という期待**が需給を上向きに歪める。新規ショートが入るほど、戻りで損切りが発生し、それがさらに上昇を加速。売り方降伏 + 続落期待の崩壊の合成。

### 検証仮説

```pine
drop_done = ta.lowest(low, 6) == low[6] and (low[6] - low) >= ta.atr(14) * 2.8
left_shoulder = ta.highest(high, 10)[6]
reclaim = close > left_shoulder
no_new_low = low >= ta.lowest(low, 4)[1]
expectation_fail = drop_done and reclaim and no_new_low
```

### 期待される結果

- Squeeze Strict と合成で PF 2.21 / 43 trades（フォワード候補）
- **D1 売り否定直後**は見送り（悪化確認済み）

### 教訓

**「まだ続くはず」という期待そのものが、続かない原因になる** — 続落期待者の損切りが次の上昇を作る。

## 12｜見送り後悔

### 心理

«入らなくて正解だった…いや、伸びてる»  
«今なら間に合う»

### 感情カテゴリ

**後悔** → **期待**（主）／恐怖

### 感情の流れ

```
後悔（最初の見送り）
    ↓
期待（伸び続けを見る）
    ↓
恐怖（完全に乗り遅れる）
    ↓
期待（最終飛び乗り）
```

### ローソク足特徴

- 20本以上のトレンド後、5本連続高値更新
- 各足の close が前足 close から ATR×0.5 以内（浅い押し目なし）
- 最後の足だけ TR 急拡大 + 上ヒゲ

### 実際に起きていること

**最初のブレイクを見送った層**が、トレンド中盤で一斉に参入。需給上は「遅れて来た買い」が厚くなり、**次の調整で最も痛い層**になる。

### 検証仮説

```python
trend = (close - close.shift(20)) / atr(14) > 3.0
shallow = all(abs(close.diff().iloc[-i]) < atr(14).iloc[-1] * 0.5 for i in range(1, 6))
upper_wick = (high - close) / (high - low + 1e-9) > 0.4
late_chase = trend & shallow & upper_wick
```

### 期待される結果

- 短期はまだ伸びうる
- 次の 12〜24本で MAE 拡大（調整）リスク高
- 正解待ち疲弊前段のサイン

### 教訓

**見送った人の再参加は、トレンドの「燃料」ではなく「終わりの近さ」** — 誰が今入っているかを常に問う。
