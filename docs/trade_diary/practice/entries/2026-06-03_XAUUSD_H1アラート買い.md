## 反省点

### 1. 一時 +50万まで行ったのに利確しなかった（最大の反省）

- 含み益 **+約50万円** まで伸びた局面があったが、**利確ルールがなく伸ばし続けた**。
- その後、雇用統計の乱高下で反転し、最終的に **-66.8万円** の損切り。
- 「勝てたトレード」を「大負け」に変えたのは、エントリーより **出口の失敗**。

### 2. SL 4330 は決めていたが、発注せず手動で早切りした

- 頭では **SL 4330** を想定していたが、**逆指値を置かなかった**。
- 最終的に **4365.64** で成行決済 → 予定SL（4330）より **35ドル手前**で損切り。
- 「早めに損切り」は一見マシだが、**+50万のあと**の決済なので結果は大損。
- **SLは「予定」ではなく、エントリー直後に逆指値で置く**。

### 3. アラート音で入った

- 投げ切りの「形」より **アラートが鳴ったこと**がトリガー。
- Webhook 400 → 手動約定。エントリー直後から含み損（-6,636）だったのに、その場で整理しなかった。

### 4. 投げ切り単独買いは弱い

- 5月高値（約4,800）からの下落途中。反転確認（棚・再ブレイク）を待っていない。
- 研究メモでも **Capitulation 直買いは単独では保留** と記録済み。

### 5. 雇用統計の日にロングを抱えた

- 決済は **6/5 23:00**（雇用統計のボラティリティが出やすい時間帯）。
- +50万の含み益がある状態で指標を跨いだのが、利益を吐き出す直接原因の一つ。

### 6. 次に守ること

| # | ルール |
|---|---|
| 1 | **含み益 +X万（例: +20〜30万）で一部 or 全利確** — ルールを先に決める |
| 2 | 指標前は **利益があっても整理**（雇用統計など） |
| 3 | **SL はエントリー直後に逆指値発注**（4330 など「予定」だけにしない） |
| 4 | アラート音 ≠ エントリー → **STOP** で一度止まる |
| 5 | 投げ切りは **WAIT → CHECK**（反転確認後のみ） |
