# シグナルレビュー・プロトコル

シグナル（アラート・マーカー）が出たとき、**エントリー前にここで売買判断を受ける**ための手順。

[← トレード日誌トップ](../README.md)

---

## いつ使うか

| タイミング | やること |
|---|---|
| アラートが鳴った直後 | **入る前に** チャート SS + このチェックを依頼 |
| 建玉保有中に逆シグナル | 既存ポジションとの矛盾（E06）を確認 |
| 指標の前日〜当日 | 保有整理が必要か確認 |

**原則: アラート音 ≠ エントリー。** 判断が `GO` になるまで待つ。

---

## 依頼するときに送るもの

1. **チャートのスクリーンショット**（シグナル付近がわかる H1/H4）
2. **銘柄・時間足・方向**（例: GBPJPY H4 買い候補）
3. **シグナル名**（例: 投げ切り / V1 SHORT / 4HT5）
4. **既存建玉**（あれば）
5. **次の重要指標**（雇用統計・FOMC 等、わかれば）

---

## 判断で見ること（チェックリスト）

### 1. 入口（入っていいか）

| チェック | NG 例 | 参照 |
|---|---|---|
| 投げ切り**単独**でないか | 青三角だけ、棚・再ブレイクなし | E01 |
| アラート音だけで入っていないか | Webhook 失敗後の手動飛び乗り | E02 |
| **棚上抜け** or **再ブレイク**があるか | 急落直後の底値拾い | [squeeze strict](../../research/market_psychology_squeeze_strict_2026-05-30.md) |
| **GBPJPY** の投げ切り買いか | 研究上除外候補 | 同上 |
| 同銘柄で**逆方向**の建玉・シグナルがないか | 投げ切り買い + V1 売り | E06 |
| 重要指標まで**2〜4時間**以内か | 雇用統計前の新規ロング | E05 |

### 2. 出口（入るなら同時に決める）

| チェック | 内容 |
|---|---|
| 逆指値 | **必ず発注**（頭の中 SL 禁止） |
| 指値 | 含み益が出る設計なら OCO で利確も同時 |
| 含み益ルール | +20〜30万 or +1R で一部利確（E04） |
| ピーク返し | 含み益ピークから -30% で全決済（E04） |

### 3. 心理ラベル

| ラベル | 意味 | 行動 |
|---|---|---|
| **STOP** | 入る根拠なし | 見送り |
| **WAIT** | シグナルは出たが確認不足 | 棚・再ブレイク・CHECK まで待つ |
| **CHECK** | 複数条件が重なった | エントリー候補。SL/TP を同時に決める |

---

## 回答フォーマット（判断側）

依頼に対して、次の形式で返す:

```
判定: GO / WAIT / NO-GO
銘柄: 
根拠: （満たした条件 or 足りない条件）
リスク: （E01〜E09 の該当）
推奨: （入るなら SL・TP・数量の目安 / 待つなら何を待つか）
```

## 6/3・6/4 で起きたこと（反面教師）

| 日付 | シグナル | 正しい判断 | 実際 |
|---|---|---|---|
| 6/3 | XAUUSD 投げ切り | **NO-GO**（単独・棚なし） | 入った → -66.8万 |
| 6/4 | GBPJPY 投げ切り | **NO-GO**（単独 + GBPJPY 除外） | 入った → 建値割れ |

レビューを挟んでいれば、どちらも **WAIT** 止まりだった可能性が高い。
