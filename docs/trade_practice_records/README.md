# トレード実践記録

作成日: 2026-06-01

ここは、作成したインジケータを実際のチャートで使ったときの記録場所です。

売買推奨ではなく、**インジケータが出した見方と、自分が実際にどう判断したか** を後から検証するために使います。

## 使うファイル

| ファイル | 用途 |
|---|---|
| [trade_practice_log.csv](trade_practice_log.csv) | すべての実践記録を一覧で見る台帳 |
| [records/](records/) | 1回ごとの詳しいメモ |
| [records/2026-06-01_usdjpy_h4_entry_159674.md](records/2026-06-01_usdjpy_h4_entry_159674.md) | 2026-06-01 USDJPY H4 159.674 の記録 |

## 記録する項目

| 項目 | 書く内容 |
|---|---|
| 日時 | エントリーした日時。分からない場合はスクショ日時 |
| 通貨ペア | USDJPY / GBPJPY / XAUUSD など |
| 時間足 | H1 / H4 など |
| 使用インジケータ | どのPineを見て判断したか |
| エントリー価格 | 実際に入った価格 |
| 売買方向 | ロング / ショート |
| 入った理由 | どの表示・形を見て入ったか |
| 損切り位置 | 入る前に決めた否定ライン |
| 利確・撤退理由 | どこで終える予定か |
| 感情 | 焦り、待てた、不安、確信、取り返したい等 |
| 結果 | 利確 / 損切り / 建値 / 保有中 |
| 次回ルール | 次に同じ場面でどうするか |

## 書き方

1. まず [trade_practice_log.csv](trade_practice_log.csv) に1行追加する
2. 必要なら `records/` に詳しいメモを作る
3. 決済後に、結果・感情・次回ルールを追記する

## 注意

- GitHubにはスクショの元パス、個人情報、口座情報は載せない
- 画像を載せる場合は、口座情報や個人情報が映っていないものだけにする
- 勝ち負けだけで判断せず、「入る前に損切り位置が決まっていたか」を必ず見る
