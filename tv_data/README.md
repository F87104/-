# TradingView データ置き場

検証で使う **TradingView エクスポート CSV** をここに置きます。  
ここに置いた CSV は **コミット対象**（gitignore しない）なので、クラウドエージェントが読めます。

## いま必要なデータ — H4（4時間足）8銘柄

各銘柄を **H4（240分）** で TradingView からエクスポートし、下のファイル名にリネームして置いてください。

| 銘柄 | ファイル名 |
|---|---|
| ドル円 | `USDJPY_H4.csv` |
| ユーロ円 | `EURJPY_H4.csv` |
| ポンド円 | `GBPJPY_H4.csv` |
| オージー円 | `AUDJPY_H4.csv` |
| ナスダック100 | `NAS100_H4.csv` |
| ゴールド | `XAUUSD_H4.csv` |
| 銀 | `XAGUSD_H4.csv` |
| スイス円 | `CHFJPY_H4.csv` |

## CSV の形式（TradingView デフォルトでOK）

先頭行はヘッダー。最低限この列があれば動きます。

```
time,open,high,low,close
1357077600,140.6785,141.796,140.6785,141.6495
...
```

- `time` は UNIX 秒（TradingView デフォルト）でも ISO 日時でもOK
- 追加のインジ列（D1 V Trigger 等）が混ざっていても無視するので問題なし

## TradingView からのエクスポート手順

1. 対象銘柄のチャートを開く
2. 時間足を **4h** にする
3. 右下「…（その他）」→ または上部メニュー → **チャートデータをエクスポート**
4. 「ISO time」または「UNIX time」どちらでも可
5. ダウンロードした CSV を上の表のファイル名にリネーム
6. このフォルダ（`tv_data/`）に置いてコミット（または GitHub Web からアップロード）

## 期間の目安

- できれば **2015-01-01 〜 現在** まで（OOS 検証のため）
- TradingView の取得可能範囲でOK。足りなければ取れる範囲で問題なし
